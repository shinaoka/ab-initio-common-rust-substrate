# PAO 基底と実球面調和関数

> 状態：試作（レビュー待ち）

## 概要〔公開〕

OpenMX の基底関数は、数値的に与えられた動径関数と実球面調和関数の積です
（マニュアル 12.1・12.2 節、技術ノート 14）。

$$
\phi\_{I,l\zeta m}(\mathbf r) = R^{(I)}\_{l\zeta}(r)\\, S\_{lm}(\hat{\mathbf r}),\qquad r = \lVert \mathbf r \rVert
$$

- 動径関数は、閉じ込めポテンシャルを加えた擬原子の Kohn–Sham 方程式の基底状態と励起状態から作られます
  （技術ノート 14、PRB **69**, 195113）。生成は ADPACK で行われ、OpenMX 本体は生成済みの表を読むだけです。
- 動径関数はカットオフ半径 \\( r\_c \\) の外で 0 です（マニュアル 12.1 節）。このため、行列は原子間距離が
  \\( r\_{c,I} + r\_{c,J} \\) を超える原子対で 0 になります。
- 任意の \\( r \\) での値は表の補間で求めます（マニュアル 12.1 節）。

## 基底の指定

### 文字列の形式〔公開〕

基底は入力ファイルの `Definition.of.Atomic.Species` ブロックで、`C6.0-s2p2d1` のような文字列で指定します
（マニュアル 8.2 節・12.1 節）。

- `-` より前（`C6.0`）：PAO ファイル名から拡張子 `.pao` を除いたもの。ファイルは PAO 用のデータディレクトリにあります。
- `-` より後（`s2p2d1`）：各角運動量で使う動径関数の数 \\( N\_l \\)。この例では s が 2 個、p が 2 個、d が 1 個。

基底関数の総数は \\( \sum\_l (2l+1) N\_l \\) です。上の例では \\( 2 + 2\cdot 3 + 1\cdot 5 = 13 \\)。

軌道最適化を使う場合は `s3>2` のように「元の動径関数の数 `>` 縮約後の数」と書きます（マニュアル 8.2 節・26 節）。
縮約なしの `s1>1` は `s1` と同じ意味です。軌道最適化の方法と入力は [Wannier 関数・アンフォールディング・局在軌道解析](wannier-unfolding.md) 5 節にあります。

### 文字列の解釈〔規約〕

- 名前の `6.0` は慣習的な命名にすぎません。計算に使うカットオフ半径は、PAO ファイル内の `radial.cutoff.pao` の値です。
- 角運動量の文字は `s`、`p`、`d`、`f`、`g`（\\( l = 0,\dots,4 \\)）です。文字の後の数字が \\( N\_l \\) です。
  書かれていない \\( l \\) は \\( N\_l = 0 \\) です。
- 原子種の最大角運動量 \\( l\_{\max} \\) は、\\( N\_l > 0 \\) となる最大の \\( l \\) です。
  途中の \\( l \\) で \\( N\_l = 0 \\) でも構いません（例：`s2d1` では p 軌道がない）。
- \\( l\_{\max} \\) がファイルの `PAO.Lmax` を超える場合、または \\( N\_l \\) がファイルの `PAO.Mul` を超える場合はエラーです。

### ファイルから選ぶ動径関数〔規約〕

各 \\( l \\) について、ファイルに格納された動径関数のうち**先頭から** \\( N\_l \\) 個
（多重度 \\( \zeta = 0, 1, \dots, N\_l - 1 \\)）を使います。並べ替えや選別はしません。

配布されている最適化済みの PAO ファイル（マニュアル 12.3 節）では、表の先頭の列がすでに最適化（縮約）後の
動径関数になっています。そのため、先頭から取るだけで最適化済みの基底が得られます。
`<Contraction.coefficients…>` ブロックの扱いは[下記](#縮約係数のブロック規約)のとおりで、読み込みでは使いません。

## 原子上の軌道の並び〔規約〕

1 原子上の基底関数は、次の入れ子の順に並びます（外側から）。

1. 角運動量 \\( l = 0, 1, \dots, l\_{\max} \\)
2. 多重度 \\( \zeta = 0, 1, \dots, N\_l - 1 \\)
3. 実球面調和関数の成分（[下記](#実球面調和関数規約)の順、\\( 2l+1 \\) 個）

つまり、原子内の番号は \\( (l, \zeta) \\) ごとに \\( 2l+1 \\) 個ずつの塊になります。
`C6.0-s2p2d1` なら次の 13 個です。

| 番号 | 軌道 |
|---|---|
| 0 | \\( s, \zeta=0 \\) |
| 1 | \\( s, \zeta=1 \\) |
| 2–4 | \\( p, \zeta=0 \\)：\\( x, y, z \\) |
| 5–7 | \\( p, \zeta=1 \\)：\\( x, y, z \\) |
| 8–12 | \\( d, \zeta=0 \\)：\\( 3z^2-1,\ x^2-y^2,\ xy,\ xz,\ yz \\) |

〔規約〕重なり行列・Hamiltonian などの原子対ブロック（[疎ブロック形式](../design/sparse-block-format.md) を参照）は、
行・列ともにこの原子内の並びを使います。scfout ファイル（マニュアル 70.1 節）も、
原子対ブロックをこの並びのまま書き出します。軌道最適化を使った場合は、縮約後の基底について同じ規則で並びます。

全体の通し番号が必要な場合は、入力ファイルの原子の順に、各原子の塊を連結します〔規約〕。

## 実球面調和関数〔規約〕

複素球面調和関数 \\( Y\_{lm} \\) は Condon–Shortley 位相の標準的な定義
（[DLMF 14.30.1](https://dlmf.nist.gov/14.30.E1)）とします。
実球面調和関数 \\( S\_{lm} \\) は正規直交で、単位ベクトル \\( \hat{\mathbf r} = (x, y, z) \\) の
多項式として、以下の符号（すべて正の係数）と並び順をとります。

| \\( l \\) | 並び順（成分の番号 0, 1, …） |
|---|---|
| 0 | \\( 1/\sqrt{4\pi} \\) |
| 1 | \\( x,\ y,\ z \\)（係数 \\( \sqrt{3/4\pi} \\)） |
| 2 | \\( 3z^2-1,\ x^2-y^2,\ xy,\ xz,\ yz \\) |
| 3 | \\( z(5z^2-3),\ x(5z^2-1),\ y(5z^2-1),\ z(x^2-y^2),\ xyz,\ x(x^2-3y^2),\ y(3x^2-y^2) \\) |
| \\( \ge 3 \\) | \\( m=0 \\)、\\( \cos\varphi \\)、\\( \sin\varphi \\)、\\( \cos 2\varphi \\)、\\( \sin 2\varphi \\)、…、\\( \cos l\varphi \\)、\\( \sin l\varphi \\) に比例する成分の順 |

**注意**：d 軌道（\\( l=2 \\)）だけは、\\( m=0 \\) の次に \\( \cos 2\varphi \\)・\\( \sin 2\varphi \\) の成分
（\\( x^2-y^2 \\)、\\( xy \\)）が来て、その後に \\( \cos\varphi \\)・\\( \sin\varphi \\) の成分
（\\( xz \\)、\\( yz \\)）が来ます。\\( l \ge 3 \\) の一般則とは順序が異なります。

各成分の規格化係数は、\\( \int d\Omega\\, S\_{lm} S\_{lm'} = \delta\_{mm'} \\) から決まる正の数です。
d 軌道の係数は順に \\( \sqrt{5/16\pi},\ \sqrt{15/16\pi},\ \sqrt{15/4\pi},\ \sqrt{15/4\pi},\ \sqrt{15/4\pi} \\) です。

複素から実への変換は、各 \\( l \\) で \\( (2l+1)\times(2l+1) \\) のユニタリ行列 \\( U^{(l)} \\) により
\\( S\_{l\mu} = \sum\_m U^{(l)}\_{\mu m} Y\_{lm} \\) と書けます。\\( U^{(l)} \\) は上の表から一意に決まります。

## PAO ファイルの形式〔規約〕

### 字句

PAO ファイル（拡張子 `.pao`）はテキスト形式です。行単位のキーワードと、
`<名前` で始まり `名前>` で終わるブロックからなります。`#` 以降はコメントです。
キーワードは行の先頭の語として探し、大文字・小文字は区別しません。同じキーワードが複数あれば最初の行を使います。

ファイルには、生成に使った ADPACK の入力や計算の記録もそのまま含まれます。
その中のキーワード（`maxL.pao`、`num.pao` など）は生成時の設定の記録で、OpenMX は読みません。

### 再実装で読む項目

| キーワード・ブロック | 意味 |
|---|---|
| `AtomSpecies` | 原子番号（仮想原子では小数をとりうる）。VPS ファイルとの整合の確認に使う |
| `PAO.Lmax` | 格納されている動径関数の最大の角運動量 |
| `PAO.Mul` | 各 \\( l \\) で格納されている動径関数の数（全 \\( l \\) で共通） |
| `radial.cutoff.pao` | カットオフ半径 \\( r\_c \\)（bohr）。ない場合の既定値は 5.0 |
| `grid.num.output` | 動径格子の点数 |
| `<valence.charge.density` … `>` | 原子の価電子密度（[中性原子ポテンシャル](neutral-atom.md) の章で使う） |
| `<pseudo.atomic.orbitals.L=l` … `>` | 角運動量 \\( l \\) の動径関数の表（\\( l = 0,\dots, \\) `PAO.Lmax`） |

それ以外のブロック（縮約係数、固有値の一覧、ADPACK の入力の写しなど）は読み飛ばしてかまいません。
例外は内殻正孔の計算で、`Lmax=` で始まる固有値の一覧（固有値の表）をペナルティ項に使います（[ESM・外部電場・内殻準位](esm-field-corehole.md) 5 節）。

### 動径関数の表

各行は \\( x = \ln r \\)、\\( r \\)（bohr）、続いて \\( \zeta = 0, 1, \dots, \\) `PAO.Mul`\\( -1 \\) の値
\\( R\_{l\zeta}(r) \\) です（1 行に `PAO.Mul` + 2 個の数）。

- 値は \\( r R(r) \\) ではなく \\( R(r) \\) そのものです。
- 格子は \\( \ln r \\) について等間隔です。価電子密度のブロックと各 \\( l \\) のブロックは同じ格子を使います。
- 格子は \\( r\_c \\) より外まで続き、\\( r > r\_c \\) の値は 0 が書かれています。

配布ファイルの例（C6.0、H5.0）：500 点、\\( r\_{\min} \approx 4\text{–}6\times 10^{-4} \\) bohr、
最後の点は \\( r\_c \\) より約 0.9 bohr 外側です。

### 規格化と直交性

〔規約〕同じ \\( l \\) の動径関数は、\\( \int\_0^\infty dr\\, r^2 R\_{l\zeta} R\_{l\zeta'} = \delta\_{\zeta\zeta'} \\) を満たします。
もとの PAO は同じ動径方程式の異なる固有状態なので直交し、最適化済みの関数はその直交変換で作られているためです。
表から台形則で計算すると、配布ファイルで \\( 10^{-4} \\) 程度の精度で成り立ちます（`tools/check_pao_file.py`）。
OpenMX は読み込み時に再規格化しません。再実装でも表の値をそのまま使います〔設計〕。

### 縮約係数のブロック〔規約〕

最適化済みの PAO ファイルの先頭には、`number.optpao` と、
`<Contraction.coefficients1` … `>`、`<Contraction.coefficients2` … `>` のようなブロックがあります。
これらは、ファイルを作ったときの記録です。

- 各ブロックは 1 回の軌道最適化の結果で、行ごとに \\( l \\)、縮約後の番号、もとの PAO の番号 \\( p \\)、係数を持ちます。
- ファイルを作る道具は、ブロックを順に読み、各 \\( l \\) について縮約後の関数を先頭から順に割り当てます。
  残りの番号はもとの PAO をそのまま使い、\\( l \\) ごとに係数ベクトルを Gram–Schmidt で正規直交化してから、
  もとの PAO の線形結合を表に書き出します。
- その結果、`<pseudo.atomic.orbitals.L=l` の表は**すでに縮約・直交化済み**の関数です。

OpenMX 本体は縮約係数のブロックを読みません。再実装でも読む必要はありません。

### OpenMX 自身が書き出す PAO ファイル〔規約〕

`CntOrb.fileout` で OpenMX 自身が書き出す縮約 PAO ファイル（[Wannier 関数・アンフォールディング・局在軌道解析](wannier-unfolding.md) 5.6 節）は、
上の配布された最適化済みファイルとは次の点で異なります。

- 縮約後の関数の後ろの列は**原始関数そのもの**で、縮約後の関数に対して直交化されていません（配布ファイルでは Gram–Schmidt で直交化済み）。
  縮約数 \\( N\_l \\) 以下の関数だけを使う限り影響しませんが、縮約数を超えて読む場合は直交しないことに注意してください。
- 係数のブロックの名前は番号なしの `<Contraction.coefficients` で、各行は `Atom= L= Mul= p= 係数` の形です（配布ファイルの `<Contraction.coefficients1` などとは別の書式）。
  このブロックも OpenMX 本体は読みません。
- `Lmax=` で始まる固有値の表は元のファイルのまま写され、内殻正孔のペナルティ項に使われます（[ESM・外部電場・内殻準位](esm-field-corehole.md)）。

## 格子の外での値〔規約〕

表の範囲外では、次のように扱います。

| 範囲 | 値 |
|---|---|
| \\( r < r\_{\min} \\)（最初の格子点より内側） | \\( l = 0 \\)：最初の格子点の値 \\( R\_{l\zeta}(r\_{\min}) \\)。\\( l \ge 1 \\)：0 |
| \\( r\_{\min} \le r \le r\_{\mathrm{last}} \\) | 表の補間 |
| \\( r > r\_{\mathrm{last}} \\)（最後の格子点より外側） | 0 |

- 原点付近では \\( R\_l(r) \propto r^l \\) なので、これは物理的に自然な扱いです。\\( r\_{\min} \\) は \\( 10^{-3} \\) bohr 未満なので、
  内側の扱いが積分に与える影響は無視できます。
- \\( r\_c < r \le r\_{\mathrm{last}} \\) では表の値が 0 なので、補間値もほぼ 0 です。
  〔設計〕再実装では \\( r \ge r\_c \\) で厳密に 0 を返してよいです。

〔設計〕補間の方式は定めません。ビット一致は求めないので、十分滑らかな補間でよいです
（例：\\( \ln r \\) を変数とする 3 次スプライン、または区分 3 次 Hermite 補間）。
既存実装も区分 3 次の補間を使っています。
