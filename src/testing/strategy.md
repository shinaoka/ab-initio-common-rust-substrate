# Test layers and fixtures [Design]

This strategy is shared by all method families.

## Layers

| Layer | Content | Typical run time | Frequency |
|---|---|---|---|
| 1. Analytic | Small problems with analytic solutions (integrals of Gaussians, properties of spherical harmonics, Poisson equation for a constant density, hydrogen-like radial solutions, ...) | seconds | every run |
| 2. Invariants | Physical properties that need no reference values (Hermiticity, translational and rotational invariance, charge sum rules, finite-difference checks of forces and stress, symmetry) | seconds to minutes | every run |
| 3. Comparison | Comparison with fixtures generated by reference codes (matrix elements, eigenvalues, energies, forces) | seconds to minutes | every run |
| 4. Regression | Converge the SCF for small systems and check total energies and forces | minutes to hours | periodically |

Fast development requires many fast tests in layers 1-3.
Layer 2 is independent of reference values, robust against future changes, and the most valuable.

## Cross-method verification

On top of the four layers, the method families are compared with each other and with external
all-electron references at the level of physical observables:

- Equations of state (e.g. on the ACWF verification set; WIEN2k/FLEUR references).
- Forces and stress on distorted structures.
- Band structures and densities of states on common k-paths.

Internal interfaces are never compared across families; only observables are.

## Fixtures

- Run the reference implementation on small systems (e.g. an H₂O molecule, Si crystal, Fe crystal,
  systems with noncollinear spin and SOC) and write out intermediate quantities.
- HDF5 is the first-choice format. Each fixture records the program and version used to generate it,
  the input file, and the names of the basis sets and pseudopotentials.
- Data whose license does not allow redistribution is not included ([Licensing](../process/license.md)).
- Tolerances are defined per physical quantity in each chapter. Bitwise agreement is not required.
