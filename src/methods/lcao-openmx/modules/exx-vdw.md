# 厳密交換・ハイブリッド汎関数・分散力補正

> 状態：初版（レビュー待ち）。分散力補正（DFT-D2・DFT-D3）は Grimme らの論文とマニュアル 54 節の方法を、
> このノートの記法で書き直し、公開資料にない規約を既存実装で確認したものです。
> 厳密交換・ハイブリッド汎関数については、公開資料の方法の整理と、既存実装（OpenMX 4.0 の派生版）では
> 入力から到達できないことの確認です。式の数値検算は `tools/check_dispersion.py` にあります。

## 目的と範囲

この章は、電子密度によらない原子位置だけの補正である分散力補正（出力ラベル `UvdW`）と、
`scf.XcType` が受け付ける `HSE`・`NLX` の扱いを定めます。

- 〔公開〕分散力補正は Grimme の DFT-D2（JCC **27**, 1787 (2006)、以下 G06）と DFT-D3
  （JCP **132**, 154104 (2010)、以下 G10。BJ 減衰は Grimme–Ehrlich–Goerigk, JCC **32**, 1456 (2011)、以下 G11）です。
  マニュアル 54 節（54.1 DFT-D2、54.2 DFT-D3）が入力を説明しています。
- 〔規約〕厳密交換（Fock 交換）とハイブリッド汎関数は、調べた版では**入力から到達できる実装がありません**。
  公開資料（Toyoda–Ozaki の電子反発積分の方法など）は将来の拡張のための参考として整理します。
- 〔設計〕全エネルギーへの入り方・力・応力の全体の形は [全エネルギーと力](energy-force.md) の章に従います。
  この章はその \\( U\_{\mathrm{vdW}} \\) の項の中身を定めます。

## 記号〔設計〕

[記法](../../../conventions/notation.md) と [全エネルギーと力](energy-force.md) の記号に加えて、次を使います。

| 記号 | 意味 |
|---|---|
| \\( Z\_I \\)（この章のみ） | 原子 \\( I \\) の原子番号（擬ポテンシャルの価電子数ではない） |
| \\( \mathbf d\_{IJ\mathbf L} = \mathbf R\_I - \mathbf R\_J - \mathbf L \\)、\\( d = \lVert \mathbf d\_{IJ\mathbf L}\rVert \\) | 原子間ベクトル（[全エネルギーと力](energy-force.md) の \\( \boldsymbol\tau\_{IJ\mathbf L} \\) の符号を反転したもの）と距離 |
| \\( \mathbf a\_k \\)（\\( k = 1,2,3 \\)） | 格子ベクトル。孤立系（`Cluster`）では計算の箱のベクトル |
| \\( h\_k = \Omega / \lVert \mathbf a\_i\times\mathbf a\_j\rVert \\) | \\( \mathbf a\_k \\) 方向の面間隔（\\( (i,j,k) \\) は巡回） |
| \\( p\_I \in \\{0, 1\\} \\) | 原子ごとの周期性フラグ（`DFTD.periodicity`） |
| \\( r\_{\mathrm{cut}} \\)、\\( r\_{\mathrm{cn}} \\) | 対の和と配位数のカットオフ（`DFTD.rcut_dftD`、`DFTD.cncut_dftD`） |
| \\( \mathrm{CN}\_I \\) | DFT-D3 の配位数 |
| \\( \Sigma\_{\gamma\eta} = \partial U / \partial\epsilon\_{\gamma\eta} \\) | ひずみ微分（[全エネルギーと力](energy-force.md) の応力の定義と同じ） |

エネルギーは Hartree、長さは bohr です。

## 入力キーワードと既定値〔規約〕〔公開〕

〔公開〕マニュアル 54 節に、キーワードの意味と既定値の多くが書かれています。
〔規約〕表の既定値は既存実装で確認した値です。マニュアルと異なるものに注を付けます。

| キーワード | 値 | 既定値 | 意味 |
|---|---|---|---|
| `scf.dftD` | on・off | off | 分散力補正を有効にする |
| `version.dftD` | 2・3 | 2 | DFT-D2 か DFT-D3 か。他の値は入力エラー（停止） |
| `DFTD3.damp` | `zero`・`bj` | **`zero`**（注 1） | DFT-D3 の減衰関数 |
| `DFTD.Unit` | `Ang`・`AU` | **`AU`**（注 2） | `DFTD.rcut_dftD` と `DFTD.cncut_dftD` の単位 |
| `DFTD.rcut_dftD` | 実数 | 100（`DFTD.Unit` の単位） | 対の和のカットオフ \\( r\_{\mathrm{cut}} \\) |
| `DFTD.cncut_dftD` | 実数 | 40（`DFTD.Unit` の単位） | 配位数のカットオフ \\( r\_{\mathrm{cn}} \\)（D3 のみ使用） |
| `DFTD.IntDirection` | 整数 3 個 | `1 1 1` | 0 にした格子方向の周期像を和から除く |
| `<DFTD.periodicity` … `DFTD.periodicity>` | 各行「原子番号 フラグ」 | 全原子 1 | 原子ごとの周期性フラグ \\( p\_I \\) |
| `DFTD.d` | 実数 | 20 | D2 の減衰の急峻さ \\( d \\) |
| `DFTD.scale6` | 実数 | D2：0.75、D3：1.0 | \\( s\_6 \\) |
| `DFTD.scale8` | 実数 | 注 3 | D3 の \\( s\_8 \\) |
| `DFTD.sr6` | 実数 | 注 3 | D3 zero 減衰の \\( s\_{r,6} \\) |
| `DFTD.a1`、`DFTD.a2` | 実数 | 注 3 | D3 BJ 減衰の \\( a\_1 \\)、\\( a\_2 \\)（\\( a\_2 \\) は常に bohr。`DFTD.Unit` の影響を受けない） |

- 注 1：マニュアル 54.2 節は既定値を `bj` と書いていますが、既存実装は `DFTD3.damp` がないとき `zero` を使います。
  〔設計〕再実装は既存実装に合わせて `zero` を既定とし、照合用の入力では常に明示します。
- 注 2：マニュアルは既定値を明示していません（54.1 節の例は `Ang`、54.2 節は `AU` を推奨）。
  既存実装は、キーワードがないと `AU` とみなします。したがって既定のカットオフは 100 bohr と 40 bohr です。
  `Ang` のときは Å から bohr に換算します（換算係数は [記法](../../../conventions/notation.md) の bohr–Å の値）。
- 注 3：D3 の残りの既定値は `scf.XcType` によります。
  `GGA-PBE` のとき \\( s\_{r,6} = 1.217 \\)、\\( a\_1 = 0.4289 \\)、\\( a\_2 = 4.4407 \\)、\\( s\_8 = 0.722 \\)（zero）または \\( 0.7875 \\)（bj）で、
  G10・G11 の PBE の値です。それ以外の汎関数では \\( s\_8 = 0.5 \\)、\\( s\_{r,6} = 1.0 \\)、\\( a\_1 = 0.5 \\)、\\( a\_2 = 5.0 \\) で、
  これは特定の汎関数に対して公表された組ではありません（マニュアルも PBE 以外では値の指定を求めています）。
- D2 の \\( s\_6 = 0.75 \\)、\\( d = 20 \\) は G06 の PBE の値です。D2 は `scf.XcType` によって既定値を変えません。
- `DFTD.periodicity` の各行の 1 列目は `Atoms.SpeciesAndCoordinates` の原子番号、2 列目がフラグ（1：周期的、0：非周期的）です。
  ブロックがあるときは原子数と同じ行数を読みます。
- D2 の補正は D2 用のキーワード（`DFTD.d`、D2 の `DFTD.scale6`）だけを、D3 は D3 用のものだけを使います。

## 対の和と周期像〔規約〕

### 和の範囲

〔規約〕分散エネルギーは単位胞内の原子 \\( I \\)、原子 \\( J \\)（\\( J = I \\) を含む）、格子ベクトル
\\( \mathbf L = n\_1\mathbf a\_1 + n\_2\mathbf a\_2 + n\_3\mathbf a\_3 \\) の三つ組の和です。三つ組 \\( (I, J, \mathbf L) \\) は次をすべて満たすときに含めます。

1. \\( 0.1 < d^2 \\)（bohr²）。\\( J = I \\)、\\( \mathbf L = 0 \\) の自己項を除くためのもので、
   0.32 bohr より近い 2 原子も黙って除かれます。
2. \\( d \le r\_{\mathrm{cut}} \\)（D2）、\\( d < r\_{\mathrm{cut}} \\)（D3 の対の和）。カットオフはなめらかに切らず、そこでエネルギーが不連続になります。
3. \\( \mathbf L = 0 \\)、または \\( p\_J = 1 \\)。
4. \\( \lvert n\_k\rvert \le N\_k \\)。\\( N\_k \\) は下の規則で決まり、`DFTD.IntDirection` の第 \\( k \\) 成分が 0 なら \\( N\_k = 0 \\)。

重み \\( w\_{IJ\mathbf L} \\) は、\\( \mathbf L \ne 0 \\) かつ \\( p\_I = 0 \\)、\\( p\_J = 1 \\) のとき 1、それ以外は \\( \tfrac12 \\) です。
すべての原子が周期的なら、通常の \\( \tfrac12\sum\_I\sum\_{J,\mathbf L} \\) です。
フラグが混在するとき、この重みにより、非周期的な原子 \\( I \\) と周期的な原子 \\( J \\) の周期像との相互作用は 1 回だけ数えられ、
非周期的な原子どうしの周期像との相互作用は含まれません。

### 周期像の範囲 \\( N\_k \\)

- 〔規約〕D3（対の和と配位数）：\\( N\_k = \lceil r / h\_k \rceil \\)（\\( r \\) は \\( r\_{\mathrm{cut}} \\) または \\( r\_{\mathrm{cn}} \\)）。
  半径 \\( r \\) の球を含む平行六面体の最小の範囲で、どんな格子でも球内の像を漏らしません。
- 〔規約〕D2：\\( N\_k = \lceil r\_{\mathrm{cut}} / \lVert\mathbf a\_k\rVert \rceil \\)。直方晶でない格子では \\( \lVert\mathbf a\_k\rVert > h\_k \\) なので、
  \\( r\_{\mathrm{cut}} \\) 以内の像の一部が漏れることがあります（`tools/check_dispersion.py` の例：斜めの格子で必要な 92 個の像のうち 52 個しか含まれない）。
  既定の \\( r\_{\mathrm{cut}} \\)（100 bohr）では漏れる像は遠く、エネルギーへの影響は小さくなります。
- 〔規約〕原子位置が変わると（MD・構造最適化・格子最適化）、\\( N\_k \\) はその時点の格子ベクトルで決め直します。

### 孤立系〔規約〕

孤立系（`scf.EigenvalueSolver Cluster`）でも、上の規則は計算の箱のベクトルを格子ベクトルとして**そのまま**適用されます。
つまり既定のままでは、箱の周期像との分散相互作用が入ります。孤立分子では `DFTD.IntDirection 0 0 0` を指定するのが正しい使い方です
（配布されている DFT-D3 の例題もそうしています）。

〔設計〕再実装は既存実装の挙動を既定として再現し、孤立系で `DFTD.IntDirection` が `0 0 0` でないときは警告を出します。

### 空原子と対応する元素〔規約〕

- 原子番号 0 の種（基底関数だけを置く空原子）は、D2 では \\( C\_6 = 0 \\) として寄与せず、D3 では和（配位数を含む）から除きます。
- D2 は \\( Z \le 54 \\)（H〜Xe）の値だけを持ち、\\( 55 \le Z \le 103 \\) の原子は \\( C\_6 = 0 \\) として黙って寄与しません。\\( Z > 103 \\) はエラーです。
- D3 は \\( 1 \le Z \le 94 \\)（H〜Pu）に対応し、それ以外の原子番号はエラー（停止）です。

## DFT-D2〔公開〕〔規約〕

〔公開〕G06 Eq. 11–13 を、上の和の範囲で書くと

$$
U\_{\mathrm{vdW}}^{\mathrm{D2}} = -\sum\_{(I,J,\mathbf L)} w\_{IJ\mathbf L}\\, s\_6\\, \frac{C\_6^{IJ}}{d^6}\\, f(d),\qquad
f(d) = \frac{1}{1 + \exp\left[-d\_{\mathrm{D}}\left(d / R\_0^{IJ} - 1\right)\right]}
$$

です。\\( d\_{\mathrm{D}} \\) は `DFTD.d`（記号 \\( d \\) と区別するため添字を付けました）、
\\( C\_6^{IJ} = \sqrt{C\_6^{I} C\_6^{J}} \\)（G06 Eq. 13）、\\( R\_0^{IJ} = R\_0^{I} + R\_0^{J} \\) です。

〔公開〕〔規約〕元素ごとの \\( C\_6 \\) と \\( R\_0 \\) は G06 Table 1 の値（\\( C\_6 \\) は J nm⁶ mol⁻¹、\\( R\_0 \\) は Å）を原子単位に換算したものです。

- \\( 1\\ \mathrm{J\\,nm^6\\,mol^{-1}} = 17.3453\\ \mathrm{Hartree\\,bohr^6} = 34.6906\\ \mathrm{Ry\\,bohr^6} \\)、\\( 1\\ \text{Å} = 1.889726\\ \mathrm{bohr} \\)。
- 既存実装は Ry bohr⁶ 単位で小数第 3 位に丸めた値（他のコードでも使われている換算表）を持ち、読み込み時に 2 で割って Hartree にします。
  例えば H は \\( C\_6 = 4.857 \\) Ry bohr⁶（G06 の 0.14 J nm⁶ mol⁻¹）、\\( R\_0 = 1.892 \\) bohr（1.001 Å）です。
  この丸めによる差は \\( C\_6 \\) の相対値で \\( 2\times10^{-3} \\) 以下です（`tools/check_dispersion.py` で数例を確認）。
- 〔設計〕再実装は G06 Table 1 から値を取り、上の係数で換算します。表を書き写すときは出典を明記し、
  既存実装との照合では \\( U\_{\mathrm{vdW}} \\) に相対 \\( 2\times10^{-3} \\) 程度の差を許すか、丸めた表を fixture として与えます。

## DFT-D3〔公開〕〔規約〕

### エネルギー

〔公開〕G10 Eq. 3 の二体項を、上の和の範囲で書きます。

$$
U\_{\mathrm{vdW}}^{\mathrm{D3}} = -\sum\_{(I,J,\mathbf L)} w\_{IJ\mathbf L}\left[ s\_6\\, C\_6^{IJ}\\, g\_6(d) + s\_8\\, C\_8^{IJ}\\, g\_8(d)\right]
$$

減衰を含めた距離の関数 \\( g\_n \\) は次のどちらかです。

- zero 減衰（G10 Eq. 4–5）：

$$
g\_n(d) = \frac{1}{d^n}\\, \frac{1}{1 + 6\left(d / (s\_{r,n} R\_0^{IJ})\right)^{-\alpha\_n}},\qquad
\alpha\_6 = 14,\quad \alpha\_8 = 16,\quad s\_{r,8} = 1
$$

  \\( R\_0^{IJ} \\) は元素の対ごとのカットオフ半径の表（G10 で定義、配布データでは Å。既存実装は bohr に換算して使う）です。
- BJ 減衰（G11 Eq. 5–6）：

$$
g\_n(d) = \frac{1}{d^n + \left(a\_1 R\_0^{IJ,\mathrm{BJ}} + a\_2\right)^n},\qquad
R\_0^{IJ,\mathrm{BJ}} = \sqrt{C\_8^{IJ}/C\_6^{IJ}}
$$

  \\( a\_2 \\) は bohr です。G11 の PBE の値 4.4407 は bohr の値として使われます（参照実装の値と一致）。
  \\( C\_8/C\_6 = 3 Q\_I Q\_J \\) は配位数によらないので、\\( R\_0^{\mathrm{BJ}} \\) も配位数によりません。

〔規約〕三体項（G10 Eq. 14–16 の Axilrod–Teller–Muto 型の \\( E^{(3)} \\)）は**実装されていません**。
既存実装の出力やコメントで「三体」と呼ばれることがあるのは、下の \\( C\_6 \\) の配位数依存から来る力の項で、エネルギーの三体項ではありません。

### \\( C\_6 \\)・\\( C\_8 \\) の決め方

〔公開〕配位数（G10 Eq. 15）：

$$
\mathrm{CN}\_I = \sum\_{J,\mathbf L} \frac{1}{1 + \exp\left[-k\_1\left(R\_{\mathrm{cov}}^{IJ}/d - 1\right)\right]},\qquad
R\_{\mathrm{cov}}^{IJ} = k\_2\left(R\_{\mathrm{cov}}^{I} + R\_{\mathrm{cov}}^{J}\right),\quad k\_1 = 16,\quad k\_2 = 4/3
$$

〔規約〕和は \\( 0.1 < d^2 < r\_{\mathrm{cn}}^2 \\) で、\\( \mathbf L = 0 \\) または \\( p\_J = 1 \\) の三つ組です（重みなし、\\( J = I \\) の周期像を含む）。
共有結合半径 \\( R\_{\mathrm{cov}} \\) は Pyykkö–Atsumi（Chem. Eur. J. **15**, 188 (2009)）の値で、金属は 10% 小さくしたもの（G10 の規約）です。

〔公開〕\\( C\_6 \\) は参照値の Gauss 重み付き平均（G10 Eq. 16–17）：

$$
C\_6^{IJ}(\mathrm{CN}\_I, \mathrm{CN}\_J) = \frac{\sum\_{a,b} C\_{6,\mathrm{ref}}^{IJ,ab}\\, L\_{ab}}{\sum\_{a,b} L\_{ab}},\qquad
L\_{ab} = \exp\left[-k\_3\left\\{(\mathrm{CN}\_I - \mathrm{CN}^{a}\_{I})^2 + (\mathrm{CN}\_J - \mathrm{CN}^{b}\_{J})^2\right\\}\right],\quad k\_3 = 4
$$

\\( a \\)（\\( b \\)）は元素 \\( I \\)（\\( J \\)）の参照系（元素ごとに最大 5 個）、\\( \mathrm{CN}^{a}\_{I} \\) はその参照配位数です。

〔規約〕

- \\( C\_{6,\mathrm{ref}} > 10^{-12} \\) の参照の組だけを和に入れます。
- 指数部は和に入る組の最大値を引いてから \\( \exp \\) を取ります（分子・分母に共通の因子なので比は変わらない）。
  こうすると \\( \mathrm{CN} \\) がすべての参照配位数から遠いときも分母が 0 になりません。極限では、配位数の空間で最も近い参照の \\( C\_6 \\) になり、
  参照実装の振る舞いと一致します。
  〔未確定〕配布されている OpenMX 4.0 本体では、分母が \\( 10^{-12} \\) を下回ると \\( C\_6 = C\_8 = 0 \\) としていた可能性があります（調べた版の変更点）。
  通常の分子・固体では差は出ませんが、参照配位数から大きく外れる原子（高配位の P など）で \\( U\_{\mathrm{vdW}} \\) が変わります。
- 〔公開〕\\( C\_8^{IJ} = 3\\, C\_6^{IJ}\\, Q\_I Q\_J \\)（G10 Eq. 6 の形）。\\( Q\_I \\) は元素ごとの係数で、
  \\( \sqrt{\tfrac12 \sqrt{Z\_I}\\, \langle r^4\rangle\_I/\langle r^2\rangle\_I} \\) にあたる値として配布データに含まれています。

### 係数表の出典と形式〔公開〕〔規約〕

〔規約〕既存実装は次の表をソースに埋め込んでいます。いずれも Grimme らが配布する DFT-D3 の参照プログラムのデータ（G10 の補足資料と同じもの）です。

| 表 | 形式 | 単位 |
|---|---|---|
| \\( C\_{6,\mathrm{ref}} \\) | 1 レコード 5 個の数：\\( C\_{6,\mathrm{ref}} \\)、元素 A の符号化番号、元素 B の符号化番号、A の参照配位数、B の参照配位数。符号化番号は \\( Z + 100\\,a \\)（\\( a \\) は 0 始まりの参照番号）。約 3.2 万レコード | Hartree bohr⁶、配位数は無次元 |
| \\( R\_0^{IJ} \\) | \\( Z \le 94 \\) の下三角（\\( Z\_A \ge Z\_B \\)）を行ごとに並べたもの | Å（読み込み時に 0.52917726 で割って bohr に） |
| \\( R\_{\mathrm{cov}} \\) | 元素ごと | Å（読み込み時に \\( k\_2 \\) を掛け、0.52917726 で割る） |
| \\( Q \\) | 元素ごと | bohr |

- 各レコードは \\( (A,a,B,b) \\) と \\( (B,b,A,a) \\) の両方に登録します（参照配位数の順も入れ替える）。
- 〔設計〕再実装はこれらの表をソースに書き写さず、配布データ（参照プログラムの係数ファイル）を実行時に読むか、
  ビルド時にその出典から生成します。表の値そのものはこのノートに載せません。
  bohr–Å の換算は既存実装に合わせて 0.52917726 を使います（[記法](../../../conventions/notation.md) の値との差は \\( 10^{-8} \\) の相対差で、照合に影響しません）。

## 力と応力〔公開〕〔規約〕

### 二体項

〔公開〕対の関数を \\( \phi\_{IJ}(d) \\)（D2 では \\( -s\_6 C\_6 f/d^6 \\)、D3 では \\( -(s\_6 C\_6 g\_6 + s\_8 C\_8 g\_8) \\) で \\( C\_6 \\) を固定したもの）とすると、

$$
\frac{\partial U}{\partial \mathbf R\_K}\Big\rvert\_{C\_6} = \sum\_{(I,J,\mathbf L)} w\_{IJ\mathbf L}\\, \phi\_{IJ}'(d)\\, \frac{\mathbf d\_{IJ\mathbf L}}{d}\\,(\delta\_{KI} - \delta\_{KJ}),\qquad
\Sigma\_{\gamma\eta}\Big\rvert\_{C\_6} = \sum\_{(I,J,\mathbf L)} w\_{IJ\mathbf L}\\, \phi\_{IJ}'(d)\\, \frac{d\_\gamma\\, d\_\eta}{d}
$$

です。導関数は

$$
\frac{d}{dd}\left[\frac{f}{d^6}\right] = \frac{f}{d^6}\left[\frac{d\_{\mathrm{D}}}{R\_0}\\,\frac{e}{1+e} - \frac{6}{d}\right],\quad e = \exp\left[-d\_{\mathrm{D}}(d/R\_0 - 1)\right]
$$

$$
\frac{d g\_n}{dd} = \frac{g\_n}{d}\left[-n + \alpha\_n\\, 6 p\_n \frac{1}{1 + 6p\_n}\right],\quad p\_n = \left(\frac{d}{s\_{r,n}R\_0}\right)^{-\alpha\_n}\quad(\text{zero}),\qquad
\frac{d g\_n}{dd} = -\frac{n\\, d^{n-1}}{\left(d^n + R^n\right)^2}\quad(\text{BJ})
$$

です（\\( R = a\_1 R\_0^{\mathrm{BJ}} + a\_2 \\)）。

### 配位数を通じた項（D3）

〔公開〕\\( C\_6 \\) が配位数を通じて原子位置によるので、連鎖律で次の項が加わります。
全原子が周期的な場合、\\( G\_{IJ} = \sum\_{\mathbf L}\left[s\_6 g\_6 + s\_8\\, 3Q\_IQ\_J\\, g\_8\right] \\)（対の和の範囲の \\( \mathbf L \\) についての和、重みなし）として

$$
\frac{\partial U}{\partial \mathrm{CN}\_I} = -\sum\_J \frac{\partial C\_6^{IJ}}{\partial \mathrm{CN}\_I}\\, G\_{IJ},\qquad
\frac{\partial U}{\partial \mathbf R\_K}\Big\rvert\_{\mathrm{CN}} = \sum\_I \frac{\partial U}{\partial\mathrm{CN}\_I}\sum\_{J,\mathbf L} c'(d)\\, \frac{\mathbf d\_{IJ\mathbf L}}{d}\\,(\delta\_{KI}-\delta\_{KJ})
$$

$$
\Sigma\_{\gamma\eta}\Big\rvert\_{\mathrm{CN}} = \sum\_I \frac{\partial U}{\partial\mathrm{CN}\_I}\sum\_{J,\mathbf L} c'(d)\\, \frac{d\_\gamma\\, d\_\eta}{d},\qquad
c'(d) = -\frac{e\_c\\, k\_1 R\_{\mathrm{cov}}^{IJ}}{(1+e\_c)^2 d^2},\quad e\_c = \exp\left[-k\_1(R\_{\mathrm{cov}}^{IJ}/d - 1)\right]
$$

です（\\( J,\mathbf L \\) の和は配位数の和の範囲）。\\( \partial C\_6/\partial\mathrm{CN}\_I \\) は Gauss 重みの商の微分
\\( \partial L\_{ab}/\partial\mathrm{CN}\_I = -2k\_3(\mathrm{CN}\_I - \mathrm{CN}^a\_I) L\_{ab} \\) から得ます。

> **検算**：D2 と D3 型の式（D3 は乱数で作った架空の参照表を使用。zero・BJ の両方）について、
> 周期的な斜方でない格子で、解析的な勾配と応力が中心差分と \\( 10^{-9} \\) 以下で一致することを
> `tools/check_dispersion.py` で確認しています。周期性フラグが混在する場合の D2 の式も同様です。

### 既存実装の規約〔規約〕

- 力は \\( -\partial U\_{\mathrm{vdW}}/\partial\mathbf R\_K \\) として、他の項の勾配に足されます。応力 \\( \Sigma \\) も他の項に足されます
  （単位と出力は [全エネルギーと力](energy-force.md) の章）。
- \\( U\_{\mathrm{vdW}} \\) は電子密度によらないので、SCF の各反復で同じ値になります。値は出力の `UvdW` に出ます。
- 周期性フラグが混在するとき、既存実装のエネルギーは上の重みの式どおりですが、勾配は、周期的な原子 \\( J \\) に対する
  「非周期的な原子 \\( I \\) と \\( J \\) の周期像」の項の寄与を落としています（\\( I \\) 側だけに足す）。
  そのため力の総和が 0 にならず、力はエネルギーの厳密な勾配ではありません。応力のその項の重みも \\( \tfrac12 \\) のままです。
  D3 では、さらに配位数（\\( \mathrm{CN}\_J \\) は \\( I \\) の周期像を数えない）と \\( G\_{IJ} \\) が \\( I, J \\) について非対称になります。
- 〔設計〕再実装は上の式（重みを含めた厳密な勾配）を実装し、既存実装との照合は全原子 \\( p\_I = 1 \\) の場合に限ります。
  フラグの混在する場合の照合はエネルギーだけにします。

## 厳密交換とハイブリッド汎関数

### 既存実装の状況〔規約〕

調べた版（OpenMX 4.0 の派生版）での事実です。

- `scf.XcType` は `LDA`、`LSDA-CA`、`LSDA-PW`、`GGA-PBE` に加えて `HSE` と `NLX` を受け付けます（大文字小文字は区別しない）。
  マニュアル 4.0 の 11 節にはこの 2 つの記載がありません。
- 格子上の交換相関の評価は、上の 4 つの汎関数だけを扱います。`HSE`・`NLX` を指定すると、どの交換相関の式も評価されず、
  入力の検査でも停止しません。得られる結果は意味のある計算ではありません。
- `HSE` のときだけ、次の 4 つのキーワードを読み、補助の配列を確保します。
  `scf.xmin.Rec.Coulomb`（既定 −14.0）、`scf.xmax.Rec.Coulomb`（既定 14.0）、`scf.Ng1.Rec.Coulomb`（既定 11）、`scf.Nrank.Rec.Coulomb`（既定 900）。
  これらは、逆空間の Coulomb 型の核（正則化した \\( 1/(\lvert\mathbf q\_1 + \mathbf q\_2\rvert^2 + c) \\)）を一様格子上で離散化し、
  特異値分解で \\( \sum\_i \lambda\_i A\_i(\mathbf q\_1) B\_i(\mathbf q\_2) \\) の分離形に近似する開発中の機能の格子の範囲・点数・階数です。
  その処理はビルドに含まれず、どこからも呼ばれません。
- Toyoda による厳密交換のモジュール（下の電子反発積分の方法を使い、Fock 行列と交換エネルギーを作るもの）のソースも含まれていますが、
  ビルドに含まれず、有効にするスイッチもどこからも立ちません。参考として、その既定の設定は、
  孤立系では裸の Coulomb 核で打ち切りなし、周期系では 10 Å で相互作用を打ち切り、遮蔽なし（\\( \omega = 0 \\)）です。
  `Cluster` と `Band` 以外の解法では使えない作りでした。
- 力・応力への厳密交換の寄与はありません。
- `NLX` に対応する処理は見当たりません。名前から非局所交換（下の PRA 2011 の方法など）を意図したものと推測できますが、〔未確定〕です。

〔設計〕再実装は `HSE`・`NLX` を受け付けたうえで「未対応」として停止します（黙って交換相関なしで計算しない）。
厳密交換を将来実装する場合は、下の公開資料の方法を出発点とし、別の章として仕様を書き起こします。

### Fock 交換の行列要素〔公開〕

以下は一般的な定義を、このノートの記法で書いたものです（実装の仕様ではなく、将来の拡張のための整理）。

実の基底関数 \\( \phi\_a \\) と、スピン \\( \sigma \\) の密度行列 \\( \rho^\sigma\_{ab} \\)（[全エネルギーと力](energy-force.md)）に対して、
電子反発積分を

$$
(ac\vert bd) = \int d^3r\\, d^3r'\\, \frac{\phi\_a(\mathbf r)\phi\_c(\mathbf r)\\, \phi\_b(\mathbf r')\phi\_d(\mathbf r')}{\lVert\mathbf r - \mathbf r'\rVert}
$$

とすると、Hartree–Fock の交換エネルギーと Fock 交換行列は

$$
E\_x^{\mathrm{HF}} = -\frac12\sum\_\sigma\sum\_{abcd} \rho^\sigma\_{ab}\\, \rho^\sigma\_{cd}\\, (ac\vert bd),\qquad
K^\sigma\_{ab} = \frac{\partial E\_x^{\mathrm{HF}}}{\partial\rho^\sigma\_{ab}} = -\sum\_{cd} (ac\vert bd)\\, \rho^\sigma\_{cd}
$$

です（実対称な \\( \rho \\) の場合。周期系では基底関数の添字に格子ベクトルが付き、\\( \mathbf k \\) 点の和になります）。
混合割合 \\( \alpha \\) のハイブリッド汎関数では、Kohn–Sham 行列に \\( \alpha K^\sigma \\) を加え、半局所汎関数の交換を \\( (1-\alpha) \\) 倍にします。
HSE 型（Heyd–Scuseria–Ernzerhof, JCP **118**, 8207 (2003)）では、\\( 1/r \\) を \\( \mathrm{erfc}(\omega r)/r \\) で置き換えた短距離部分だけを Fock 交換で扱います。
\\( K \\) は \\( \rho \\) に依存するので、SCF の各反復で作り直します。

### 電子反発積分の計算法〔公開〕

Toyoda–Ozaki（JCP **130**, 124114 (2009)、技術資料 [exx/JCP2009](https://www.openmx-square.org/exx/JCP2009/index.html)）の方法を、
このノートの [Fourier 変換の規約](../../../conventions/notation.md) で導出し直します。

1. 2 つの基底関数の積を、ある点 \\( \mathbf c \\) を中心とする 1 つの関数 \\( F(\mathbf r - \mathbf c) = \phi\_a(\mathbf r - \mathbf R\_a)\phi\_c(\mathbf r - \mathbf R\_c) \\) とみなし、
   球面調和関数で展開します：\\( F(\mathbf r) = \sum\_{lm} P\_{lm}(r)\\, Y\_{lm}(\hat{\mathbf r}) \\)。
   \\( \mathbf c \\) から離れた中心の基底関数の展開には、Löwdin の α 関数（球 Bessel 変換で作る）を使います。
   同様に \\( G(\mathbf r - \mathbf c') \\) を作ります。
2. \\( 1/r \\) の Fourier 変換 \\( 4\pi/k^2 \\) と Parseval の等式から、\\( \mathbf R = \mathbf c' - \mathbf c \\) として

$$
(F\vert G) = \frac{1}{2\pi^2}\int d^3k\\, \frac{1}{k^2}\\, \tilde F^{\ast}(\mathbf k)\\, \tilde G(\mathbf k)\\, e^{-i\mathbf k\cdot\mathbf R}
$$

3. \\( \tilde F(\mathbf k) = 4\pi\sum\_{lm}(-i)^l\\, \tilde P\_{lm}(k)\\, Y\_{lm}(\hat{\mathbf k}) \\)（\\( \tilde P\_{lm} \\) は球 Bessel 変換）と、
   \\( e^{-i\mathbf k\cdot\mathbf R} \\) の平面波展開を代入し、角度積分を Gaunt 係数 \\( G(lm;\\, l'm',\\, \lambda\mu) \\)
   （[二中心積分](two-center-overlap-kinetic.md) と同じ定義）で行うと

$$
(F\vert G) = 32\pi \sum\_{lm}\sum\_{l'm'}\sum\_{\lambda\mu} i^{\\,l - l' - \lambda}\\, G(lm;\\, l'm',\\, \lambda\mu)\\, Y^{\ast}\_{\lambda\mu}(\hat{\mathbf R})
\int\_0^\infty dk\\, \tilde P^{\ast}\_{lm}(k)\\, \tilde Q\_{l'm'}(k)\\, j\_\lambda(kR)
$$

   となります（\\( 32\pi = (4\pi)^3/(2\pi^2) \\)、\\( Q \\) は \\( G \\) の動径関数）。重なりの式と同じ構造で、核が \\( k^{-2} \\) だけ違います。
4. 遮蔽した核 \\( \mathrm{erfc}(\omega r)/r \\) では、\\( 4\pi/k^2 \\) を \\( (4\pi/k^2)(1 - e^{-k^2/4\omega^2}) \\) に置き換えます。
5. 球 Bessel 変換には高速な方法（Toyoda–Ozaki, CPC **181**, 277 (2010)、技術資料 [exx/CPC2009](https://www.openmx-square.org/exx/CPC2009/index.html)）が使えます。
   JCP 2009 は、積関数の角運動量を \\( l \lesssim 15 \\) まで取る必要があること、動径格子 1024 点程度、最後の \\( k \\) 積分を
   Gauss–Laguerre 求積（約 60 点）で行うこと、原子位置の微分（力）を和則で減らして計算することを報告しています。

> **検算**：上の式 3 を、s–s と p–s の Gauss 型の積密度（裸の核と erfc 遮蔽の核）について数値積分し、
> 閉じた式と相対 \\( 10^{-6} \\) 以下で一致することを `tools/check_dispersion.py` で確認しています。

> **技術資料 JCP2009 についての注記**：同資料の最終式は位相因子の形がこの式と異なって見えますが、
> 同資料は Fourier 変換の符号（\\( e^{+i\mathbf k\cdot\mathbf r} \\) 型）と複素共役の付け方がこのノートと異なるため、そのままは比べられません。
> 再実装ではこのノートの規約の式を使います（上の検算で確認済み）。

### モデル交換正孔による交換汎関数〔公開〕

Toyoda–Ozaki（PRA **83**, 032515 (2011)、技術資料 [exx/PRA2011](https://www.openmx-square.org/exx/PRA2011/index.html)）は、
交換正孔を \\( \mathrm{erfc}(\mu s) \\) で短距離と長距離に分け、短距離部分は厳密に、長距離部分は水素型 1s 軌道から作るモデル正孔
（Becke–Roussel 型）で置き換える交換汎関数を提案しています。モデル正孔の 2 つのパラメータは、各点で正孔の 0 次のモーメントを厳密に、
1 次のモーメントをできるだけ合わせるように決め、ポテンシャルは連鎖律で解析的に求めます。
同論文の計算は著者らの原子用の有限要素法コードで行われ、OpenMX での実装・入力は公開資料にありません。
調べた版の OpenMX にも対応する処理はありません（`NLX` との関係は〔未確定〕）。

## 端の場合〔規約〕〔設計〕

- 〔規約〕`scf.dftD off`（既定）では \\( U\_{\mathrm{vdW}} = 0 \\) で、力・応力への寄与もありません。
- 〔規約〕原子が 1 個だけの孤立系では \\( U\_{\mathrm{vdW}} = 0 \\)（周期像を除いた場合）。
- 〔規約〕カットオフでエネルギーが不連続なので、MD でエネルギー保存がわずかに破れます。既定のカットオフでは不連続の大きさは
  1 対あたり \\( C\_6/r\_{\mathrm{cut}}^6 \\)、すなわち \\( 10^{-11} \\)〜\\( 10^{-10} \\) Hartree 程度です。
- 〔規約〕2 原子が 0.32 bohr より近づくと、その対は和から黙って外れます。
- 〔設計〕再実装も同じ不連続を持たせ（照合のため）、なめらかなカットオフは別のオプションとします。

## 設計〔設計〕

モジュール化した再実装のための要件です。

- **分散力補正のモジュール**は、入力として原子番号、原子位置、格子ベクトル（孤立系では箱）、周期性フラグ、方向のマスク、
  パラメータの組（バージョン、減衰関数、\\( s\_6, s\_8, s\_{r,6}, a\_1, a\_2, d\_{\mathrm{D}} \\)、カットオフ）を取り、
  \\( U\_{\mathrm{vdW}} \\)、原子ごとの勾配、\\( \Sigma \\)（3×3）を返す純関数とします。電子状態のデータには依存させません。
- パラメータの既定値は `scf.XcType` から決める部分（D3 の PBE の値）を、入力の解釈の層で解決してからモジュールに渡します。
- 係数表（D2 の G06 Table 1、D3 の参照データ）は外部データとして読み込み、出典・版・単位を記録します。
- 周期像の列挙は D3 の面間隔による規則で行うのが正しいですが、D2 の既存実装との照合のため、
  \\( \lVert\mathbf a\_k\rVert \\) による規則を互換オプションとして持ちます。
- 三体項（ATM 項）は互換性のため既定では無効とし、追加する場合は別のオプションとします。
- 大きな系では、原子対の和を近傍リスト（セル分割）で \\( O(N) \\) にします。既存実装は原子対の全組を走査する \\( O(N^2) \\) の作りです。
- `HSE`・`NLX` は未対応として停止します。厳密交換を加える場合は、Fock 行列を [H(R)・S(R) 疎ブロック形式](../design/sparse-block-format.md)
  の原子対ブロックとして作り、SCF の Hamiltonian 組み立てに加える層を別に設けます。
