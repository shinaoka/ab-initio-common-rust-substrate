# Nonlocal pseudopotential

> Status: prototype (awaiting review). The separable-form equations were re-derived in the notation of this note from the original papers and technical note 2.
> The spin-orbit matrix elements and the j-averaging rule were confirmed as behavior of the existing implementation and checked with `tools/check_nonlocal.py`.

## Overview [Public]

- OpenMX uses separable norm-conserving pseudopotentials of the Morrison–Bylander–Kleinman (MBK) form
  (manual Sec. 13.1. MBK is positioned as the norm-conserving version of Vanderbilt's ultrasoft pseudopotential).
  Each \\( l \\) (each \\( j \\) in the fully relativistic case) may have several projectors.
- The pseudopotential is the sum of a local part \\( V\_{\mathrm{loc}}(r) \\) and a separable nonlocal part \\( \hat V\_{\mathrm{NL}} \\).
  The local part is incorporated into the [neutral-atom potential](neutral-atom.md), so this chapter treats only the nonlocal part
  (technical note 1 Eq. 17–20, 23, 31).
- The pseudopotential data are given per species in a VPS file (extension `.vps`).
  The correspondence with species is specified by the third column of `Definition.of.Atomic.Species` in the input (manual Sec. 13.1).
  VPS files are generated by ADPACK (ADPACK manual "Output files").

## 1. Separable form

### 1.1 Kleinman–Bylander and Blöchl [Public]

The Kleinman–Bylander (KB) form is the separable form that reproduces, for a reference state \\( \psi\_l \\),
\\( \Delta V\_l = V\_l - V\_{\mathrm{loc}} \\), i.e. a semilocal pseudopotential \\( V\_l(r) \\) minus the local part
(Kleinman–Bylander, PRL **48**, 1425 (1982)).

$$
\hat V\_{\mathrm{NL}} = \sum\_{lm} \frac{\lvert \Delta V\_l\\, \psi\_l\\, S\_{lm} \rangle \langle S\_{lm}\\, \psi\_l\\, \Delta V\_l \rvert}{\langle \psi\_l \rvert \Delta V\_l \lvert \psi\_l \rangle}
$$

Blöchl (PRB **41**, 5414 (1990)) extended this to a form that improves accuracy by using several radial functions \\( \bar R\_{l\zeta} \\) for one \\( l \\).
Technical note 2 Eq. 47–53 uses \\( \bar R\_{l\zeta} \\) orthogonalized by Gram–Schmidt and
\\( c\_{l\zeta} = \int r^2 dr\\, \bar R\_{l\zeta}\\, \Delta V\_l\\, \bar R\_{l\zeta} \\),
and writes it as a diagonal sum over projectors \\( \Delta V\_l \bar R\_{l\zeta} \\) with coefficients \\( 1/c\_{l\zeta} \\).
In ADPACK, `Blochl.projector.num` is the number of projectors per \\( l \\); 1 corresponds to the KB form
(ADPACK manual "Separable form").

### 1.2 MBK form [Public]

In the MBK form (Morrison–Bylander–Kleinman, PRB **47**, 6728 (1993)), from pseudo wave functions \\( \psi\_i \\) at several reference energies
\\( \varepsilon\_i \\) of the same \\( l \\), one constructs

$$
\chi\_i = (\varepsilon\_i - \hat T - V\_{\mathrm{loc}})\\, \psi\_i,\qquad
B\_{ij} = \langle \psi\_i \vert \chi\_j \rangle
$$

and sets

$$
\hat V\_{\mathrm{NL}} = \sum\_{ij} \lvert \chi\_i \rangle (B^{-1})\_{ij} \langle \chi\_j \rvert
$$

When the generalized norm-conservation condition holds, \\( B \\) is symmetric. The reference energies are given in the fifth column of the ADPACK input
`pseudo.NandL` (ADPACK manual "How the MBK scheme is different from the others").
When there is only one state for an \\( l \\), the scheme switches to the TM form, and the number of projectors is determined by `Blochl.projector.num` (same section).

**Diagonalized form** [Design]: diagonalize the symmetric matrix \\( B \\) as \\( B = U \operatorname{diag}(b\_k) U^{\mathsf T} \\) and set

$$
\beta\_k = \frac{1}{\sqrt{\lvert b\_k \rvert}} \sum\_i \chi\_i U\_{ik},\qquad \varepsilon\_k = \operatorname{sign}(b\_k)
$$

Then \\( \hat V\_{\mathrm{NL}} = \sum\_k \lvert \beta\_k \rangle \varepsilon\_k \langle \beta\_k \rvert \\)
(numerically confirmed with `tools/check_nonlocal.py`). KB, Blöchl and MBK can all be written in this "projectors and diagonal coefficients" form.

### 1.3 Representation in this note [Design]

The nonlocal part of atom \\( K \\) is written, with projector index \\( p = 1, \dots, N\_p \\), as

$$
\hat V^{K}\_{\mathrm{NL}} = \sum\_{p} \varepsilon\_p \sum\_{\mu=1}^{2l\_p+1} \lvert \beta\_{p\mu}^{K} \rangle \langle \beta\_{p\mu}^{K} \rvert,\qquad
\beta\_{p\mu}^{K}(\mathbf r) = b\_p(\lvert \mathbf r - \mathbf R\_K \rvert)\\, S\_{l\_p \mu}\left(\widehat{\mathbf r - \mathbf R\_K}\right)
$$

- \\( l\_p \\) is the angular momentum of projector \\( p \\), \\( b\_p(r) \\) its radial function, and \\( \varepsilon\_p \\) the projector energy (diagonal coefficient).
- \\( S\_{l\mu} \\) are the real spherical harmonics of the [PAO basis](pao-basis.md), with the same component ordering.
- The coefficient matrix \\( D \\) is diagonal in the projectors (\\( D\_{pq} = \varepsilon\_p \delta\_{pq} \\)).
  A nondiagonal \\( D \\) does not appear in the VPS file format and is not treated.
- Units: chosen so that \\( \varepsilon\_p\\, b\_p(r)\\, b\_p(r') \\) is in Hartree·bohr⁻³.
  In files with \\( \varepsilon\_p = \pm 1 \\), the magnitude is carried by \\( b\_p \\), whose unit is \\( \mathrm{Hartree}^{1/2}\\,\mathrm{bohr}^{-3/2} \\).

[Convention] In the MBK-form files of DFT\_DATA19, all projector energies are \\( \pm 1 \\); that is, the projectors are stored after the diagonalization
and normalization above. However, values other than \\( \pm 1 \\) appear in old-format files (e.g. `C02.vps`) and in
virtual-crystal files mixing two kinds of files (e.g. `C5Si5.vps`, with energies \\( \pm 0.5 \\)).
Implementations must treat \\( \varepsilon\_p \\) as a general real number.

## 2. VPS file format [Convention]

### 2.1 Overall structure

- Text format. As in PAO files, it consists of line-based "keyword value" entries and blocks starting with `<name` and ending with `name>`.
  Text after `#` is a comment; case is not significant. Logical values are `on`/`yes`/`true` etc. and `off`/`no`/`false` etc.
- The first half of the file contains a verbatim copy of the ADPACK input file used for generation (`vps.type`, `number.vps`,
  `<pseudo.NandL`, `Blochl.projector.num`, etc.), followed by a record of all-electron eigenvalues and total energies.
  In the new format, these are not used for reading.
- The second half contains the data blocks read by the main program. In the new format these are the three blocks `<project.energies`, `<Pseudo.Potentials`,
  and `<density.PCC`.
- If the same keyword appears more than once, the first value is used.

### 2.2 Items read

| Keyword / block | Meaning | Default |
|---|---|---|
| `AtomSpecies` | Atomic number. Fractional for virtual atoms (must match the PAO file) | Required |
| `total.electron` | Total number of electrons at pseudopotential generation | `AtomSpecies` |
| `valence.electron` | Number of valence electrons | 0 |
| `grid.num.output` | Number of radial grid points \\( N\_r \\) | Required |
| `j.dependent.pseudo.potentials` | Whether the data are j-dependent (fully relativistic) | off |
| `charge.pcc.calc` | Whether a partial-core-correction density block is included | off |
| `<project.energies` | Number, angular momenta and energies of projectors (new format) | — |
| `<Pseudo.Potentials` | Radial grid, local potential, projector radial functions | Required |
| `<density.PCC` | Partial-core-correction density (when `charge.pcc.calc` is on) | — |

The effective ionic charge is \\( Z\_v = \\) `valence.electron` \\( + \\) `AtomSpecies` \\( - \\) `total.electron`
(to support files generated in an ionic state). This is consistent with the asymptotic form of the local potential \\( V\_{\mathrm{loc}}(r) \to -Z\_v/r \\)
(e.g. \\( rV\_{\mathrm{loc}} = -4 \\) at the last grid point of `C_PBE19.vps`).

If `AtomSpecies` differs between the PAO file and the VPS file, the program stops with an error (except for empty atoms).

### 2.3 `<project.energies` block (new format)

The first line is the number of projectors \\( N\_p \\); the following \\( N\_p \\) lines describe each projector \\( p \\).

- Non-j-dependent: each line has two columns, "\\( l\_p \\)  \\( \varepsilon\_p \\)".
- j-dependent: each line has three columns, "\\( l\_p \\)  \\( \varepsilon\_{p+} \\)  \\( \varepsilon\_{p-} \\)".
  \\( + \\) denotes \\( j = l\_p + 1/2 \\) and \\( - \\) denotes \\( j = l\_p - 1/2 \\).

Energies are in Hartree. The line order defines the projector index \\( p \\). In DFT\_DATA19 files,
projectors are arranged in ascending \\( l \\) with projectors of the same \\( l \\) grouped together, but the reader must use \\( l\_p \\) of each line
and not assume any ordering. \\( N\_p = 0 \\) is also allowed (`E.vps` for empty atoms).

### 2.4 `<Pseudo.Potentials` block

It consists of \\( N\_r \\) lines, each of which is

| Column | Content |
|---|---|
| 1 | \\( x = \ln r \\) |
| 2 | \\( r \\) (bohr) |
| 3 | Local potential \\( V\_{\mathrm{loc}}(r) \\) (Hartree) |
| 4 onward (non-j-dependent) | \\( b\_1(r), b\_2(r), \dots, b\_{N\_p}(r) \\) |
| 4 onward (j-dependent) | \\( b\_{1+}(r), b\_{1-}(r), b\_{2+}(r), b\_{2-}(r), \dots \\) (for each projector, in the order \\( j = l+1/2 \\), \\( j = l-1/2 \\)) |

The number of columns is \\( 3 + N\_p \\) if not j-dependent and \\( 3 + 2N\_p \\) if j-dependent
(e.g. `C_PBE19.vps` has \\( N\_p = 12 \\), is j-dependent, and has 27 columns).

- The grid is equally spaced in \\( \ln r \\) (in `C_PBE19.vps`, \\( x \\) runs from −7.5 to 2.8 with 500 points).
- The projector values are \\( b\_p(r) \\) itself, not \\( r\\, b\_p(r) \\). Near the origin they behave as \\( b\_p \propto r^{l\_p} \\).
  Overlaps are used in the form \\( \int\_0^\infty r^2 dr\\, b\_p(r) R(r) \\).
- Projectors approach 0 rapidly outside the cutoff radius used at generation, but values are stored up to the end of the table
  (in `C_PBE19.vps`, they fall below \\( 10^{-6} \\) times the maximum beyond roughly 1.3–3 bohr).
  The truncation radius of the projectors is not stated explicitly in the file.

### 2.5 `<density.PCC` block

Present only when `charge.pcc.calc` is on. Each line is "\\( \ln r \\)  \\( r \\)  \\( \rho\_{\mathrm{pcc}}(r) \\)", and
the grid must be the same as that of `<Pseudo.Potentials` (an error if not).
\\( \rho\_{\mathrm{pcc}} \\) is an electron number density (bohr⁻³), and \\( \int 4\pi r^2 \rho\_{\mathrm{pcc}}\\, dr \\) is the partial core charge
(about 0.25 for `C_PBE19.vps`). This density is added to the valence density in the exchange-correlation calculation and
is used in [Real-space grid, Poisson, exchange-correlation](grid-poisson-xc.md). When off, it is treated as 0.

### 2.6 Old format

A file without the `<project.energies` block is read as old format. DFT\_DATA19 contains no old-format files.

- The old format cannot hold j-dependent data. If `j.dependent.pseudo.potentials` is on, it is an error.
- `number.vps` is the number of description lines, and each line of `<pseudo.NandL` is "index  principal quantum number  \\( l \\)  cutoff radius".
- `local.part.vps` is the index (0-based) of the line used for the local part. The remaining lines, excluding this one, become
  projectors one by one in that order. If the index is out of range, no line is excluded.
- Each line of the `<projection.energies` block is "index  \\( \varepsilon\_p \\)", in the same order as the projectors.
- The columns of `<Pseudo.Potentials` are the same as in the non-j-dependent case of the new format.

### 2.7 Interpolation and out-of-range values

- The interpolation scheme is in principle free (as in the [PAO basis](pao-basis.md), bitwise agreement is not required).
- Outside the maximum grid radius, values are 0.
- Inside the minimum grid radius, \\( l = 0 \\) projectors are extrapolated from the first interval, and \\( l \ge 1 \\) projectors are 0.
  The minimum radius is about \\( e^{-7.5} \approx 5.5\times 10^{-4} \\) bohr, so the effect on results is negligible.

## 3. Assembly of matrix elements

### 3.1 Overlap with projectors [Public]

The overlap between a basis function \\( \phi\_a \\) on atom \\( I \\) (\\( l\_a \\), radial function \\( R\_a \\)) and a projector \\( \beta^{K}\_{p\mu} \\) of atom \\( K \\) is written

$$
C^{K}\_{a,p\mu}(\boldsymbol\tau) = \int d^3 r\\, \phi\_a(\mathbf r)\\, \beta\_{p\mu}(\mathbf r - \boldsymbol\tau),\qquad
\boldsymbol\tau = \mathbf R\_K + \mathbf L' - \mathbf R\_I
$$

This is the same as the [two-center integral](two-center-overlap-kinetic.md) overlap \\( S\_{ab}(\boldsymbol\tau) \\)
with the partner's radial function \\( R\_b \\) replaced by \\( b\_p \\) (the equations of Sec. 2 of that chapter and the conversion to real spherical harmonics).
Since both basis functions and projectors are real, \\( C \\) is real.

### 3.2 Matrix elements (scalar case) [Public]

The matrix element between \\( \phi\_a \\) on atom \\( I \\) and \\( \phi\_b \\) on atom \\( J \\) shifted by lattice vector \\( \mathbf L \\) is

$$
V^{\mathrm{NL}}\_{ab}(\mathbf L) = \sum\_{K,\mathbf L'} \sum\_{p} \varepsilon\_p \sum\_{\mu}
C^{K}\_{a,p\mu}(\mathbf R\_K + \mathbf L' - \mathbf R\_I)\\;
C^{K}\_{b,p\mu}(\mathbf R\_K + \mathbf L' - \mathbf R\_J - \mathbf L)
$$

(the nonlocal term of technical note 1 Eq. 11, 78, written out by substituting the separable form).
The sum runs over all atoms \\( K \\) in the unit cell and their periodic images \\( \mathbf L' \\).
Terms with \\( K = I \\) or \\( K = J \\) (the same periodic image) are included.
In spin-unpolarized or collinear-spin calculations, this matrix is added equally to both up and down spins.

### 3.3 Range of third atoms [Convention]

The existing implementation selects the third atoms contributing to matrix elements using only the PAO cutoff radius (the 6.0 in a basis specification `C6.0-…`,
[PAO basis](pao-basis.md)).

- Atom pairs \\( (I, J+\mathbf L) \\) are computed only within the same range as the overlap matrix, \\( \lvert \boldsymbol\tau\_{IJ} \rvert \le r\_{c,I} + r\_{c,J} \\).
  Nonlocal matrix elements of atom pairs outside this range are discarded.
- A third atom \\( K + \mathbf L' \\) is included in the sum only if it satisfies both \\( \lvert \boldsymbol\tau\_{IK} \rvert \le r\_{c,I} + r\_{c,K} \\) and
  \\( \lvert \boldsymbol\tau\_{JK} \rvert \le r\_{c,J} + r\_{c,K} \\).
  Here \\( r\_{c,K} \\) is the **PAO** cutoff radius of atom \\( K \\), not the extent of its projectors.

Since the projector extent \\( r\_\beta \\) is much smaller than the PAO cutoff radius, the terms dropped by the second condition are effectively 0.
The first condition, on the other hand, is an approximation. Physically, nonzero elements can exist for \\( \lvert \boldsymbol\tau\_{IJ} \rvert \\) up to \\( r\_{c,I} + r\_{c,J} + 2r\_\beta \\),
but they are discarded so that the sparsity pattern matches that of the overlap matrix.
The damping function below smooths this truncation.

### 3.4 Damping function [Convention]

The whole set of nonlocal matrix elements of atom pair \\( (I, J+\mathbf L) \\) is multiplied by the following function of the interatomic distance \\( d = \lvert \boldsymbol\tau\_{IJ} \rvert \\)

$$
f(d) = \begin{cases}
1 & d < r\_{\mathrm{cut}} - 1 \\\\
10t^3 - 15t^4 + 6t^5,\quad t = r\_{\mathrm{cut}} - d & r\_{\mathrm{cut}} - 1 \le d \le r\_{\mathrm{cut}} \\\\
0 & d > r\_{\mathrm{cut}}
\end{cases},\qquad r\_{\mathrm{cut}} = r\_{c,I} + r\_{c,J}
$$

(lengths in bohr, transition width 1 bohr). \\( f \\) is continuous up to the second derivative at both ends (`tools/check_nonlocal.py`).
The same damping function is also used for matrix elements of the neutral-atom potential via the projector expansion.

[Design] The reimplementation adopts this truncation and damping function as is. The reasons are that it allows comparison with fixtures of the existing implementation and
that the set of atom pairs in the sparse block format ([H(R)/S(R) sparse block format](../design/sparse-block-format.md)) can be
shared with the overlap matrix. An exact calculation without truncation is kept as a separate path for verification.

### 3.5 Periodic images

\\( \mathbf L \\) and \\( \mathbf L' \\) range over all lattice vectors that satisfy the distance conditions above.
\\( V^{\mathrm{NL}}\_{ab}(\mathbf L) \\) is stored as one block of \\( H(\mathbf R) \\).
Hermiticity \\( V^{\mathrm{NL}}\_{ab}(\mathbf L) = V^{\mathrm{NL}}\_{ba}(-\mathbf L) \\) holds (real symmetric in the scalar case).

## 4. Treatment of j-dependent data in the scalar-relativistic case

### 4.1 Method [Public]

When `scf.SpinOrbit.Coupling` is off (default), j-dependent pseudopotentials are averaged with the j degeneracy as weights
and used as scalar-relativistic pseudopotentials (manual Sec. 38.3).
Since the j degeneracy is \\( 2j+1 \\), the weights for \\( j = l \pm 1/2 \\) at angular momentum \\( l \\) are

$$
w\_+ = \frac{l+1}{2l+1},\qquad w\_- = \frac{l}{2l+1}
$$

The manual does not state what is averaged (the operator, or the projectors and energies).

### 4.2 Averaging in the existing implementation [Convention]

The existing implementation averages the projector radial functions and the energies **separately**.

$$
\bar b\_p(r) = w\_+ b\_{p+}(r) + w\_- b\_{p-}(r),\qquad
\bar\varepsilon\_p = w\_+ \varepsilon\_{p+} + w\_- \varepsilon\_{p-}
$$

Then \\( \bar\varepsilon\_p\\, \lvert \bar b\_p S \rangle\langle \bar b\_p S \rvert \\) is used in the equation of Sec. 3.2.
The same applies to collinear-spin calculations and to noncollinear calculations without spin-orbit coupling.

[Public] (derived) On the other hand, the spin average of the j-dependent operator (Sec. 5) (1/2 of the spin trace) is

$$
\sum\_p \left( w\_+ \varepsilon\_{p+} \lvert b\_{p+} S \rangle\langle b\_{p+} S \rvert + w\_- \varepsilon\_{p-} \lvert b\_{p-} S \rangle\langle b\_{p-} S \rvert \right)
$$

(\\( \tfrac12 \mathrm{Tr}\_\sigma P\_\pm = w\_\pm \\) confirmed with `tools/check_nonlocal.py`). The two agree if \\( b\_{p+} = b\_{p-} \\) and
\\( \varepsilon\_{p+} = \varepsilon\_{p-} \\), but differ in general.
DFT\_DATA19 contains projectors with opposite signs for the same projector, such as \\( \varepsilon\_{p+} = 1 \\), \\( \varepsilon\_{p-} = -1 \\)
(e.g. \\( l = 1 \\) of `Ba_PBE19.vps` and `Ag_PBE19.vps`); in this case the existing implementation's \\( \bar\varepsilon\_p \\) becomes \\( 1/(2l+1) \\).

[Design] By default, the same averaging as the existing implementation (averaging projectors and energies separately) is used and compared with fixtures.
The operator average is provided as an option, and the difference between the two (total energy, bands) is recorded.

## 5. Full relativity and spin-orbit coupling

### 5.1 j-dependent nonlocal operator [Public]

A j-dependent pseudopotential is written using projections onto the subspaces of total angular momentum \\( j = l \pm 1/2 \\) obtained by coupling angular momentum \\( l \\) and spin 1/2
(Bachelet–Schlüter, PRB **25**, 2103 (1982); Theurich–Hill, PRB **64**, 073106 (2001); technical note 2 Eq. 40–58).
Technical note 2 writes it as a sum of projections onto spinors \\( \Phi\_{JM} \\) constructed with Clebsch–Gordan coefficients.
Since the eigenvalues of \\( \mathbf L\cdot\boldsymbol\sigma = 2\\,\mathbf L\cdot\mathbf S \\) are \\( l \\) for \\( j = l+1/2 \\) and \\( -(l+1) \\) for \\( j = l-1/2 \\),
these projections can be written as

$$
P^{(l)}\_{+} = \frac{(l+1)\\,\mathbb 1 + \mathbf L\cdot\boldsymbol\sigma}{2l+1},\qquad
P^{(l)}\_{-} = \frac{l\\,\mathbb 1 - \mathbf L\cdot\boldsymbol\sigma}{2l+1}
$$

(\\( P\_+ + P\_- = \mathbb 1 \\), \\( P\_\pm^2 = P\_\pm \\), \\( \mathrm{Tr}\\,P\_\pm = 2j+1 \\)).
Using these, the nonlocal operator of atom \\( K \\) is

$$
\hat V^{K}\_{\mathrm{NL}} = \sum\_p \sum\_{s=\pm} \varepsilon\_{ps} \sum\_{\mu\nu} \sum\_{\sigma\sigma'}
\lvert \beta^{K}\_{ps\mu}\\, \sigma \rangle \left(P^{(l\_p)}\_{s}\right)^{\sigma\sigma'}\_{\mu\nu} \langle \beta^{K}\_{ps\nu}\\, \sigma' \rvert
$$

The radial function of \\( \beta^{K}\_{ps\mu} \\) is \\( b\_{ps} \\). The matrix elements of \\( P \\) are taken in the product basis of real spherical harmonics and spin
\\( \lvert S\_{l\mu} \rangle \lvert \sigma \rangle \\) (\\( \sigma = \uparrow, \downarrow \\) are eigenstates of \\( \sigma\_z \\)).
That \\( P\_\pm \\) above agrees with the projection by Clebsch–Gordan spinors has been confirmed for \\( l = 1, 2, 3 \\)
with `tools/check_nonlocal.py`.

### 5.2 Angular momentum matrices in real spherical harmonics [Design]

Let \\( (L\_k)\_{\mu\nu} = \langle S\_{l\mu} \vert \hat L\_k \vert S\_{l\nu} \rangle \\), \\( \hat{\mathbf L} = -i\\,\mathbf r\times\nabla \\), and
\\( L\_\pm = L\_x \pm i L\_y \\). In spin space,

$$
\mathbf L\cdot\boldsymbol\sigma = \begin{pmatrix} L\_z & L\_- \\\\ L\_+ & -L\_z \end{pmatrix}
$$

(rows and columns both in the order \\( \uparrow, \downarrow \\)). In the real basis, \\( L\_z \\) is a purely imaginary antisymmetric matrix, \\( L\_- \\) is an antisymmetric matrix, and
\\( L\_+ = L\_-^{\dagger} \\). With the ordering and signs of the [PAO basis](pao-basis.md), the nonzero upper-triangular elements are as follows
(component indices are 0-based; computed with `tools/check_nonlocal.py`).

- \\( l = 1 \\) (\\( x, y, z \\)): \\( (L\_z)\_{01} = -i \\); \\( (L\_-)\_{02} = 1 \\), \\( (L\_-)\_{12} = -i \\).
- \\( l = 2 \\) (\\( 3z^2-r^2, x^2-y^2, xy, xz, yz \\)): \\( (L\_z)\_{12} = -2i \\), \\( (L\_z)\_{34} = -i \\);
  \\( (L\_-)\_{03} = -\sqrt3 \\), \\( (L\_-)\_{04} = \sqrt3\\, i \\), \\( (L\_-)\_{13} = 1 \\), \\( (L\_-)\_{14} = i \\),
  \\( (L\_-)\_{23} = -i \\), \\( (L\_-)\_{24} = 1 \\).
- \\( l = 3 \\) (in the order of the PAO basis table): \\( (L\_z)\_{12} = -i \\), \\( (L\_z)\_{34} = -2i \\), \\( (L\_z)\_{56} = -3i \\);
  \\( (L\_-)\_{01} = -\sqrt6 \\), \\( (L\_-)\_{02} = \sqrt6\\, i \\),
  \\( (L\_-)\_{13} = -\sqrt{5/2} \\), \\( (L\_-)\_{14} = \sqrt{5/2}\\, i \\),
  \\( (L\_-)\_{23} = -\sqrt{5/2}\\, i \\), \\( (L\_-)\_{24} = -\sqrt{5/2} \\),
  \\( (L\_-)\_{35} = -\sqrt{3/2} \\), \\( (L\_-)\_{36} = \sqrt{3/2}\\, i \\),
  \\( (L\_-)\_{45} = -\sqrt{3/2}\\, i \\), \\( (L\_-)\_{46} = -\sqrt{3/2} \\).

The lower triangle follows from antisymmetry (\\( (L\_z)\_{\nu\mu} = -(L\_z)\_{\mu\nu} \\), \\( (L\_-)\_{\nu\mu} = -(L\_-)\_{\mu\nu} \\)).

[Convention] The spin-orbit matrix elements of the existing implementation agree with those written with these \\( L\_z \\), \\( L\_- \\) and \\( P\_\pm \\) of Sec. 5.1
in all elements for \\( l = 1, 2, 3 \\) (including signs).

### 5.3 Matrix elements [Public] (derived)

With the same symbols as Sec. 3.2, the matrix element for spin pair \\( (\sigma, \sigma') \\) is

$$
V^{\mathrm{NL},\sigma\sigma'}\_{ab}(\mathbf L) = \sum\_{K,\mathbf L'} \sum\_{p} \sum\_{s=\pm} \varepsilon\_{ps} \sum\_{\mu\nu}
C^{K}\_{a,ps\mu}\\, \left(P^{(l\_p)}\_{s}\right)^{\sigma\sigma'}\_{\mu\nu}\\, C^{K}\_{b,ps\nu}
$$

Written block by block (with \\( C\_{a,s} \\) as a row vector in \\( \mu \\)):

$$
V^{\uparrow\uparrow} = \sum \frac{\varepsilon\_{+}}{2l+1} C\_{a,+}\left[(l+1) + L\_z\right] C\_{b,+}^{\mathsf T}
{}+ \frac{\varepsilon\_{-}}{2l+1} C\_{a,-}\left[l - L\_z\right] C\_{b,-}^{\mathsf T}
$$

$$
V^{\downarrow\downarrow} = \sum \frac{\varepsilon\_{+}}{2l+1} C\_{a,+}\left[(l+1) - L\_z\right] C\_{b,+}^{\mathsf T}
{}+ \frac{\varepsilon\_{-}}{2l+1} C\_{a,-}\left[l + L\_z\right] C\_{b,-}^{\mathsf T}
$$

$$
V^{\uparrow\downarrow} = \sum \frac{\varepsilon\_{+}}{2l+1} C\_{a,+} L\_- C\_{b,+}^{\mathsf T}
{}- \frac{\varepsilon\_{-}}{2l+1} C\_{a,-} L\_- C\_{b,-}^{\mathsf T},\qquad
V^{\downarrow\uparrow}\_{ab}(\mathbf L) = \overline{V^{\uparrow\downarrow}\_{ba}(-\mathbf L)}
$$

(the sums are over \\( K, \mathbf L', p \\); the range and damping function of Secs. 3.3 and 3.4 apply unchanged).

- The real part of the diagonal blocks is the j-dependent weighted sum, and the imaginary part is the \\( L\_z \\) term (the diagonal part of spin-orbit).
- \\( V^{\uparrow\downarrow} \\) is complex. The existing implementation stores the real and imaginary parts of the three blocks \\( \uparrow\uparrow \\), \\( \downarrow\downarrow \\), \\( \uparrow\downarrow \\),
  and constructs \\( \downarrow\uparrow \\) from Hermiticity [Convention].
- When non-j-dependent species (scalar files) are mixed in, the contribution of such an atom \\( K \\) is given by the equation of Sec. 3.2 and
  is added equally to \\( \uparrow\uparrow \\) and \\( \downarrow\downarrow \\) [Convention].
- The existing implementation handles j-dependent projectors only for \\( l \le 3 \\), and stops with an error if \\( l \ge 4 \\) is present [Convention].

### 5.4 Input keywords and conditions [Public] [Convention]

- `scf.SpinOrbit.Coupling` (on/off, default off): includes spin-orbit coupling self-consistently (manual Sec. 38.1).
  j-dependent VPS files are used.
- [Convention] It can be turned on only for noncollinear calculations (`scf.SpinPolarization` is `NC`).
  Turning it on in a collinear spin-polarized or spin-unpolarized calculation stops with an input error.
- [Convention] Even when on, if none of the VPS files used is j-dependent, it is switched off and the calculation continues.
- [Convention] When off, j-dependent files are averaged by the rule of Sec. 4.

### 5.5 Scaling the strength of spin-orbit coupling [Public] [Convention]

[Public] The `<scf.SO.factor` block allows the spin-orbit coupling strength to be changed per species and per \\( l \\) (s, p, d, f)
(manual Sec. 38.2). Each line has the form "species name  s factor  p factor  d factor  f factor", with the symbol
`s`, `p`, `d`, `f` placed before each factor. A factor of 1.0 is the strength of the actual atom. All species must be given up to f.
Note that ADPACK also has a `<SO.factor` block that changes the strength at pseudopotential generation, but this is a different thing
(ADPACK manual "Enhancement or depletion of a spin-orbit coupling").

[Convention]

- This block is read only in noncollinear calculations with `scf.SpinOrbit.Coupling` on. If the block is absent, all factors are 1.
- The symbols on each line (`s` etc.) are skipped, and the factors correspond to \\( l = 0, 1, 2, 3 \\) in order.
- The factor \\( \lambda\_l \\) acts on the projector radial functions. With \\( \bar b = (b\_+ + b\_-)/2 \\) and \\( \delta b = (b\_+ - b\_-)/2 \\),

$$
b\_{p+} \to \bar b\_p + \lambda\_{l\_p}\\, \delta b\_p,\qquad b\_{p-} \to \bar b\_p - \lambda\_{l\_p}\\, \delta b\_p
$$

  are substituted, and the energies \\( \varepsilon\_{p\pm} \\) are left unchanged.

[Public] (derived) With this method, spin-orbit coupling does not vanish completely even at \\( \lambda = 0 \\). When \\( b\_{p+} = b\_{p-} = \bar b\_p \\),

$$
\varepsilon\_{+} P\_+ + \varepsilon\_{-} P\_- = \frac{(l+1)\varepsilon\_+ + l\varepsilon\_-}{2l+1}\\,\mathbb 1 + \frac{\varepsilon\_+ - \varepsilon\_-}{2l+1}\\,\mathbf L\cdot\boldsymbol\sigma
$$

so for projectors with \\( \varepsilon\_{p+} \ne \varepsilon\_{p-} \\) the \\( \mathbf L\cdot\boldsymbol\sigma \\) term remains (`tools/check_nonlocal.py`).
The reimplementation uses the same substitution as the existing implementation and verifies this property in tests.

## 6. Derivatives with respect to atomic positions (forces)

[Public] The energy of the nonlocal term is \\( E\_{\mathrm{NL}} = \sum \rho\\, V^{\mathrm{NL}} \\) (contraction with the density matrix), and
its contribution to forces splits into the product of the derivative of the matrix elements with the density matrix, and the product of the derivative of the overlap matrix with the energy density matrix (the Pulay term,
treated in [Total energy and forces](energy-force.md)) (technical note 1 Eq. 62, 71–75).
Technical note 1 states that the derivatives of the matrix elements are evaluated analytically. Here the former is written out.

[Public] (derived) Including the noncollinear case, we write

$$
E\_{\mathrm{NL}} = \sum\_{\mathbf L} \sum\_{ab} \sum\_{\sigma\sigma'} \rho^{\sigma\sigma'}\_{ab}(\mathbf L)\\, V^{\mathrm{NL},\sigma\sigma'}\_{ab}(\mathbf L)
$$

This is a sum of products without complex conjugation; split into real and imaginary parts it is \\( \mathrm{Re}\\,\rho\\,\mathrm{Re}\\,V - \mathrm{Im}\\,\rho\\,\mathrm{Im}\\,V \\),
with a factor 2 on the spin-off-diagonal \\( \uparrow\downarrow \\)
(the contraction rule of Sec. 1.4 of [Energy, forces and stress for noncollinear and spin-orbit calculations](noncollinear-energy-force.md); agreement with the band energy has been confirmed numerically, and the existing implementation also uses this contraction [Convention]).
The definition of \\( \rho \\) and the phase convention follow [k-points and Bloch sums](kpoints-bloch.md), [Density matrix and charge mixing](density-mixing.md) and [H(R)/S(R) sparse block format](../design/sparse-block-format.md).
(The contraction with \\( \rho^{\sigma'\sigma}\_{ba}(-\mathbf L) \\) in an earlier version was changed to the form above, because the sign of the product of imaginary parts did not match the \\( \rho \\) convention of these chapters.)
Including the damping function of Sec. 3.4 as \\( V\_{ab} = f(d\_{IJ})\\, h\_{ab} \\) (\\( h \\) is the sum before damping), the derivative with respect to the position of atom \\( X \\) is

$$
\frac{\partial V\_{ab}}{\partial \mathbf R\_X} = f'(d\_{IJ})\\, \frac{\partial d\_{IJ}}{\partial \mathbf R\_X}\\, h\_{ab} + f(d\_{IJ})\\, \frac{\partial h\_{ab}}{\partial \mathbf R\_X},\qquad
\frac{\partial d\_{IJ}}{\partial \mathbf R\_J} = -\frac{\partial d\_{IJ}}{\partial \mathbf R\_I} = \hat{\boldsymbol\tau}\_{IJ}
$$

(\\( f' \\) is the derivative with respect to \\( d \\). Since \\( t = r\_{\mathrm{cut}} - d \\), \\( f'(d) = -(30t^2 - 60t^3 + 30t^4) \\)).
Since the overlap \\( C^{K}\_{a}(\boldsymbol\tau) \\) depends only on \\( \boldsymbol\tau = \mathbf R\_K + \mathbf L' - \mathbf R\_I \\), the derivative of \\( h \\) is

$$
\frac{\partial h\_{ab}}{\partial \mathbf R\_X} = \sum\_{K,\mathbf L'}\sum\_{p,s} \varepsilon\_{ps}
\left[ (\delta\_{XK} - \delta\_{XI})\\, \nabla\_{\boldsymbol\tau} C^{K}\_{a,ps}\\; P\\; C^{K\\,\mathsf T}\_{b,ps}
{}+ (\delta\_{XK} - \delta\_{XJ})\\, C^{K}\_{a,ps}\\; P\\; \nabla\_{\boldsymbol\tau} C^{K\\,\mathsf T}\_{b,ps} \right]
$$

(in the scalar case, \\( P \\) is the identity and the sum over \\( s \\) has a single term).
\\( \nabla\_{\boldsymbol\tau} C \\) is computed with the equations of Sec. 6 of [Two-center integrals](two-center-overlap-kinetic.md).

- Note that a force acts on the third atom \\( K \\) itself (the \\( X = K \\) term).
- For the \\( K = I \\) term, \\( \delta\_{XK} - \delta\_{XI} = 0 \\), consistent with the fact that the overlap on the same atom does not depend on position.
- The force contribution is \\( \mathbf F\_X = -\partial E\_{\mathrm{NL}}/\partial \mathbf R\_X \\). Under translation of the whole system, \\( \sum\_X \mathbf F\_X = 0 \\).
- [Convention] The force calculation of the existing implementation also includes the term from the derivative of the damping function.

## 7. Numerical parameters [Convention]

- \\( C^{K}\_{a,p\mu} \\) is computed in reciprocal (wave-number) space, as for two-center integrals. The spherical Bessel transform of the radial functions
  integrates in real space from the minimum radius to "the PAO cutoff radius of atom \\( K \\) + 0.5 bohr",
  using an equally spaced grid of `1DFFT.NumGridR` (default 900) points. The transformed function is held as a table on an equally spaced grid of
  `1DFFT.NumGridK` (default 900) points from 0 to \\( k\_{\max} \\).
- \\( k\_{\max} = \sqrt{E\_{\mathrm{cut}}} \\) bohr⁻¹, where \\( E\_{\mathrm{cut}} \\) is `1DFFT.EnergyCutoff` (Ry, default 3600).
- The integral over wave number (corresponding to \\( I^{(0)}\_L \\) of the two-center integrals) is done by the trapezoidal rule on a grid dividing \\( 10^{-6} \\) to \\( k\_{\max} \\)
  into `1DFFT.NumGridR` equal intervals.

Since bitwise agreement is not required, these are treated as defaults that may be changed as [Design], and it is confirmed that the differences from fixtures stay within the tolerances.
