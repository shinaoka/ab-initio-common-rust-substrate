# ESM 法・外部電場・電荷ドープ・仮想原子・内殻準位

> 状態：初版（レビュー待ち）。ESM 法は Otani–Sugino（PRB **73**, 115407 (2006)）と Ohwaki ら（JCP **136**, 134101 (2012)）、
> 内殻準位は技術ノート 24（Ozaki–Lee, PRL **118**, 026401 (2017)）、入力はマニュアル 30–32・49・60 節に基づき、
> このノートの記法で導き直しました。公開資料に記載のない規則は既存実装の挙動として〔規約〕で補っています。
> 数値の検算は `tools/check_esm_field_corehole.py` で行っています。

## この章の範囲

この章は、標準の周期境界の計算（[グリッド・Poisson・XC](grid-poisson-xc.md)、[全エネルギーと力](energy-force.md)）に
外から加える 5 つの機能を扱います。

| 機能 | 主な入力 | 変更する量 |
|---|---|---|
| 電荷ドープ | `scf.system.charge` | 電子数、Hartree ポテンシャルの \\( \mathbf G=0 \\) 成分の扱い |
| ESM 法 | `ESM.switch` ほか | 一方向の Poisson 方程式の境界条件（\\( \delta V\_H \\)） |
| 一様電場 | `scf.Electric.Field` | 格子上の局所ポテンシャルに鋸歯状ポテンシャルを加える |
| 仮想原子 | 分数の `AtomSpecies` を持つ PAO・VPS ファイル | 種のデータだけ（計算の流れは変わらない） |
| 内殻正孔（XPS） | `scf.core.hole`、`<core.hole.state` | Hamiltonian にペナルティ項、Hartree ポテンシャルの分割 |

NEGF の電極境界条件は範囲外です。

## 記号〔設計〕

[記法](../../../conventions/notation.md)、[グリッド](grid-poisson-xc.md)、[全エネルギーと力](energy-force.md) の記号に加えて次を使います。

| 記号 | 意味 |
|---|---|
| \\( Q \\) | `scf.system.charge`（電子 1 個の電荷を \\( -1 \\) とした系の余分な電荷。正で正孔ドープ） |
| \\( \delta n = n - n^{a} \\) | 価電子密度と原子密度の重ね合わせの差（[グリッド](grid-poisson-xc.md) 2.2 節） |
| \\( \delta V\_H \\) | \\( \delta n \\) が作る Hartree ポテンシャル。電子 1 個のポテンシャルエネルギーとして符号を取る（\\( \nabla^2\delta V\_H = -4\pi\delta n \\)） |
| \\( \mathbf a\_1 \\)、\\( a = \lVert\mathbf a\_1\rVert \\) | ESM で表面法線方向に取る格子ベクトルとその長さ |
| \\( z \\) | ESM の法線方向の座標。セルの中心を 0 とし \\( -z\_0 \le z \le z\_0 \\)、\\( z\_0 = a/2 \\) |
| \\( \mathbf G\_\parallel \\)、\\( G\_\parallel = \lVert\mathbf G\_\parallel\rVert \\) | 面内の逆格子ベクトル |
| \\( g\_m = 2\pi m/a \\) | 法線方向の波数（\\( m \\) は整数） |
| \\( \Delta \\) | 内殻正孔のペナルティの大きさ（Hartree） |
| \\( V\_{\mathrm{ef}} \\) | 一様電場の鋸歯状ポテンシャル（電子のポテンシャルエネルギー） |

## 1. 電荷ドープ

### 1.1 電子数〔公開〕〔規約〕

〔公開〕マニュアル 31 節：`scf.system.charge` に余分な電荷を与えます（既定 0。正で正孔ドープ、負で電子ドープ、分数も可）。

〔規約〕占有させる電子数は \\( N\_{\mathrm e} = \sum\_I Z\_I - Q \\) です（\\( Z\_I \\) は擬ポテンシャルの価電荷）。
化学ポテンシャルの決め方は [密度行列と電荷ミキシング](density-mixing.md) 1 節、初期密度は同章 6 節
（初期密度の電子数には \\( Q \\) を反映しない）を参照してください。

### 1.2 補償電荷〔公開〕〔規約〕

〔公開〕マニュアル 31 節：Poisson 方程式を FFT で解くため、余分な電荷は符号が逆の一様な背景電荷で中和されます。
したがって電荷状態の異なる全エネルギーには背景電荷との静電エネルギーが含まれ、そのままでは比較できません
（孤立系の正しい扱いはマニュアル 61 節）。

〔規約〕このノートの記法では次のとおりです。

- \\( \int\_\Omega\delta n\\,d^3r = N\_{\mathrm e} - \sum\_I Z\_I = -Q \\)。周期系の Poisson 方程式（[グリッド](grid-poisson-xc.md) 3.1 節）は
  \\( \mathbf G = 0 \\) 成分を 0 にするので、\\( \delta n \\) から一様な \\( -Q/\Omega \\) を差し引いた密度を解いていることになります。
  `UH1` \\( = \tfrac12\Delta V\sum\_{\mathbf n}\delta n\\,\delta V\_H \\) は、この背景電荷との相互作用を含んだ値です。
- Makov–Payne 型などの補正項はありません。
- `scf.coulomb.cutoff on` のときは球形 Coulomb カットオフ（[グリッド](grid-poisson-xc.md) 3.3 節）で \\( \mathbf G=0 \\) 成分も
  \\( 2\pi R\_c^2\\,\delta\tilde n(0) \\) として残るので、背景電荷は置かれません。荷電した孤立系はこちらで扱います。
- ESM 法（2 節）では、`on2`・`on3`・`on4` が荷電系を扱えます（余分な電荷は理想金属に誘起された電荷で打ち消されます）。
- 入力キーワード `Atoms.NetCharge` は読み込まれますが、計算には使われません。

## 2. ESM 法（effective screening medium）

### 2.1 考え方〔公開〕

Otani–Sugino（2006）：スラブを含むセルの法線方向（\\( z \\)）の両端 \\( z = \pm z\_0 \\) の外側に、誘電率 1 の真空か
誘電率 \\( \infty \\) の理想金属を置き、面内は周期境界、法線方向はその境界条件で Poisson 方程式を解きます。
面内 2 次元 Fourier 変換した \\( \delta n(\mathbf G\_\parallel, z) \\) について

$$
\left(\frac{d^2}{dz^2} - G\_\parallel^2\right)\delta V\_H(\mathbf G\_\parallel, z) = -4\pi\\,\delta n(\mathbf G\_\parallel, z)
$$

を、媒質の条件を満たす Green 関数 \\( g(G\_\parallel; z, z') \\) で

$$
\delta V\_H(\mathbf G\_\parallel, z) = \int\_{-z\_0}^{z\_0} g(G\_\parallel; z, z')\\, \delta n(\mathbf G\_\parallel, z')\\, dz'
$$

と解きます。

〔公開〕Ohwaki ら（2012）：OpenMX では、原子核と原子密度 \\( n^{a} \\) の組（中性原子ポテンシャル \\( V^{\mathrm{na}} \\)）が
短距離で、長距離の静電相互作用は \\( \delta n \\) だけが担う（[全エネルギーと力](energy-force.md)）ので、
ESM の Green 関数は \\( \delta n \\) にだけ適用します。

### 2.2 入力とセル〔公開〕〔規約〕

〔公開〕マニュアル 49.1 節：

| キーワード | 値 | 既定 | 意味 |
|---|---|---|---|
| `ESM.switch` | `off`・`on1`・`on2`・`on3`・`on4` | `off` | 下端｜セル｜上端の媒質。`on1`＝真空｜真空、`on2`＝金属｜金属、`on3`＝真空｜金属、`on4`＝`on2` に電位差を加えたもの |
| `ESM.direction` | `x`・`y`・`z` | `x` | 法線方向の Cartesian 軸 |
| `ESM.potential.diff` | 実数（eV） | 0 | `on4` の 2 つの金属の電位差 |
| `ESM.buffer.range` | 実数（Å） | 10.0 | 原子と媒質の間に空ける距離（2.7 節を参照） |
| `ESM.wall.switch`・`.position`・`.height` | 2.6 節 | | MD 用の壁 |

- `on1` は電気的に中性（`scf.system.charge` 0）の系に限ります。`on2`・`on3`・`on4` は荷電系を扱えます。

〔規約〕

- 法線方向は**第 1 格子ベクトル** \\( \mathbf a\_1 \\) に取ります。\\( \mathbf a\_1 \\) は `ESM.direction` の軸に平行で正の向き、
  \\( \mathbf a\_2, \mathbf a\_3 \\) はその軸の成分が 0 でなければなりません（違反は入力エラー）。
  `<Atoms.UnitVectors` がない（孤立系の箱を自動で作る）入力もエラーです。
- 分率座標で与えた原子の \\( \mathbf a\_1 \\) 方向の座標は \\( [0,1] \\) になければなりません（他の方向のように折り返さず、エラー）。
- `on1`・`on2`・`on3` で `ESM.potential.diff` が 0 でなければ入力エラーです。`on1` の電荷中性は検査しません。
- **媒質の位置**：下端の媒質は格子の原点を通る \\( \mathbf a\_1 \\) に垂直な面、上端はそれを \\( \mathbf a\_1 \\) だけずらした面です。
  ESM のときは格子の原点の決め方（[グリッド](grid-poisson-xc.md) 1.4 節）が次のように変わります。法線軸の成分について、
  原子位置の算術平均 \\( c \\) を格子間隔 \\( h = a/N\_1 \\) の整数倍 \\( \mathrm{trunc}(c/h)\\,h \\)（0 方向への切り捨て）に置き換えてから、
  1.4 節の式で原点を決めます。他の 2 成分は 1.4 節のままです。
  したがって媒質の面はちょうど \\( x = 0, a \\) ではなく、原子の重心に応じて格子間隔程度ずれます。
  `scf.fixed.grid` を与えた場合はその原点を使います。
- 座標 \\( z \\) は、法線軸に沿った「格子の原点からの距離」\\( x\_\perp \\) から \\( z = x\_\perp - z\_0 \\) です。
  格子点 \\( n\_1 = 0, \dots, N\_1-1 \\) は \\( x\_\perp = n\_1 h \\) にあり、\\( z = -z\_0 \\) の点（下端の面）は格子点、上端の面は周期像の格子点です。

〔設計〕面内の k 点は通常どおり、法線方向の k 点は 1 点にすることを推奨します（既存実装は検査しません）。

### 2.3 Green 関数〔公開〕

Otani–Sugino（2006）の 3 つの境界条件を、このノートの符号（\\( \delta V\_H \\) は電子のポテンシャルエネルギー、\\( \delta n \\) は電子密度で正）で書きます。
理想金属の面は \\( z\_1 = z\_0 \\)（セルの端）に置きます。

**`on1`（真空｜真空）**：\\( z\to\pm\infty \\) で電場 0。

$$
g(G\_\parallel; z,z') = \frac{2\pi}{G\_\parallel} e^{-G\_\parallel\lvert z-z'\rvert},\qquad
g(0; z,z') = -2\pi\lvert z-z'\rvert
$$

\\( G\_\parallel = 0 \\) の定数の任意性は、上の形（付加定数 0）で固定します。

**`on2`（金属｜金属、接地）**：\\( z = \pm z\_1 \\) で \\( \delta V\_H = 0 \\)。

$$
g(G\_\parallel; z,z') = \frac{4\pi\\,\sinh\bigl(G\_\parallel(z\_< + z\_1)\bigr)\sinh\bigl(G\_\parallel(z\_1 - z\_>)\bigr)}{G\_\parallel\sinh(2G\_\parallel z\_1)},\qquad
g(0; z,z') = \frac{4\pi\\,(z\_< + z\_1)(z\_1 - z\_>)}{2z\_1}
$$

（\\( z\_< = \min(z,z') \\)、\\( z\_> = \max(z,z') \\)）。

**`on3`（真空｜金属）**：下端（\\( z\to-\infty \\)）は真空、上端 \\( z = z\_1 \\) は接地した金属。

$$
g(G\_\parallel; z,z') = \frac{2\pi}{G\_\parallel}\left(e^{-G\_\parallel\lvert z-z'\rvert} - e^{G\_\parallel(z+z'-2z\_1)}\right),\qquad
g(0; z,z') = 4\pi\\,(z\_1 - z\_>)
$$

`on3` の \\( G\_\parallel = 0 \\) では、下側の電場は 0 で、全電荷 \\( q = \int\delta n \\) からの電気力線はすべて上端の金属で終わります
（\\( d\delta V\_H/dz = -4\pi q \\)、\\( z \to z\_1 \\)）。

**`on4`（金属｜金属＋電位差）**：`on2` の解に、電荷によらない一次関数

$$
V\_{\mathrm{bias}}(z) = \frac{\Delta\Phi}{2}\left(1 - \frac{z}{z\_1}\right),\qquad \Delta\Phi = \texttt{ESM.potential.diff}\ (\mathrm{eV} \to \mathrm{Hartree})
$$

を \\( \mathbf G\_\parallel = 0 \\) 成分に加えます〔規約〕。すなわち下端の金属で電子のポテンシャルエネルギーが \\( \Delta\Phi \\)、上端で 0 です。
電子は上端側（電子のエネルギーの低い側）に引かれます。電場の大きさは \\( \Delta\Phi/a \\) です。

3 つの Green 関数が対称（\\( g(z,z') = g(z',z) \\)）で、それぞれの境界条件を満たすことをスクリプトで確認しています。

### 2.4 数値解法〔規約〕

既存実装の結果に影響する選択は次のとおりです（計算の流れは書きません）。

- **補間**：\\( \delta n \\) の法線方向の位相を \\( z = x\_\perp - z\_0 \\) の座標系に移します。
   すなわち \\( \delta n(\mathbf G\_\parallel, z) = \sum\_m n\_m(\mathbf G\_\parallel)\\, e^{i g\_m z} \\) という、区間 \\( [-z\_0, z\_0) \\) 上の三角補間を作ります
   （\\( m \\) の範囲は [グリッド](grid-poisson-xc.md) 3.1 節と同じ写し方）。
- **積分**：各 \\( \mathbf G\_\parallel \\) について、Green 関数の積分を**区間 \\( [-z\_0, z\_0] \\) 上で解析的に**行います。
   \\( e^{\pm i g\_m z\_0} = (-1)^m \\) を使うと、例えば `on1` は

$$
\delta V\_H(\mathbf G\_\parallel, z) = \sum\_m n\_m\left[\frac{4\pi e^{ig\_m z}}{G^2} - \frac{2\pi(-1)^m}{G\_\parallel G^2}
\left((G\_\parallel + ig\_m)\\,e^{G\_\parallel(z - z\_0)} + (G\_\parallel - ig\_m)\\,e^{-G\_\parallel(z + z\_0)}\right)\right],\quad G^2 = G\_\parallel^2 + g\_m^2
$$

$$
\delta V\_H(0, z) = -2\pi n\_0\left(z^2 + z\_0^2\right) + \sum\_{m\ne0} n\_m\left[\frac{4\pi e^{ig\_m z}}{g\_m^2} - \frac{4\pi i(-1)^m z}{g\_m} - \frac{4\pi(-1)^m}{g\_m^2}\right]
$$

   になります。第 1 項は周期境界の解、残りは区間の端から来る斉次解（\\( e^{\pm G\_\parallel z} \\)、または \\( 1, z \\)）です。
   `on2`・`on3` も同じく、Green 関数を「自由空間の項＋\\( e^{\pm G\_\parallel z}e^{\pm G\_\parallel z'} \\) の積の和」（\\( G\_\parallel = 0 \\) では \\( z, z' \\) の多項式）に分け、
   \\( \int\_{-z\_0}^{z\_0} e^{s G\_\parallel z'} e^{ig\_m z'}dz' = 2(-1)^m\sinh(sG\_\parallel z\_0)/(sG\_\parallel + ig\_m) \\) などの初等積分で評価します。
- **端の平滑化**：\\( \mathbf G\_\parallel = 0 \\) 成分だけ、セルの端 \\( z = \pm z\_0 \\) をはさむ 9 点（端の格子点とその両側 4 点ずつ）の値を、
   両外側の点（端から \\( \pm 4h \\)）の値と傾きに一致する 3 次多項式（Hermite 補間）で置き換えます。
   傾きには、周期境界の項を除いた解析的な項（\\( n\_0 \\) の 2 次式と一次の項）の微分を使います。
   法線方向に周期像と接する端では三角補間が不連続を作るため、その点を取り除くための処置です。
   端の近くは真空（2.7 節）なので、エネルギーへの影響は小さいはずです（〔未確定〕：影響の大きさは未測定）。

〔設計〕端に密度がない（2.7 節の緩衝領域がある）場合、2 の解析的な区間積分は、
「周期境界の解 \\( V\_{\mathrm{per}} \\) に斉次解 \\( A e^{G\_\parallel z} + B e^{-G\_\parallel z} \\)（\\( G\_\parallel=0 \\) では \\( A + Bz \\)）を加え、
端での境界条件で \\( A, B \\) を決める」方法と一致します。境界条件は

| 境界 | \\( G\_\parallel > 0 \\) | \\( G\_\parallel = 0 \\) |
|---|---|---|
| 真空（上端） | \\( V'(z\_0) = -G\_\parallel V(z\_0) \\) | \\( V'(z\_0) = -2\pi q \\) |
| 真空（下端） | \\( V'(-z\_0) = G\_\parallel V(-z\_0) \\) | `on1`：\\( V'(-z\_0) = 2\pi q \\)、`on3`：\\( V'(-z\_0) = 0 \\) |
| 金属 | \\( V(\pm z\_1) = 0 \\) | \\( V(\pm z\_1) = 0 \\) |

で、`on1` の \\( G\_\parallel = 0 \\) は定数を \\( V(z\_0) + V(-z\_0) = -4\pi z\_0 q \\)（\\( g = -2\pi\lvert z-z'\rvert \\) の規約）で固定します。
\\( n\_0 \\) の項には特解 \\( -2\pi n\_0 z^2 \\) を使います。再実装はどちらの方法でもよく、スクリプトで両者と直接の数値積分の一致を確認しています。

### 2.5 エネルギーと力〔規約〕

- `UH1` は周期境界の場合と同じく \\( \tfrac12\Delta V\sum\_{\mathbf n}\delta n\\,\delta V\_H \\) で、\\( \delta V\_H \\) に ESM の解を使います。
  他のエネルギー項は変わりません。理想金属に誘起された電荷との相互作用は、この \\( \tfrac12\int\delta n\\,\delta V\_H \\) に含まれます。
- `on4` では \\( V\_{\mathrm{bias}} \\) も \\( \delta V\_H \\) の一部として `UH1` に入るので、エネルギーには \\( \tfrac12\int\delta n\\,V\_{\mathrm{bias}} \\) が入ります。
  一方 Hamiltonian と力には \\( V\_{\mathrm{bias}} \\) がそのまま入るので、`on4` の `Utot` は密度について変分的ではありません。
- 力は、[グリッド](grid-poisson-xc.md) 6 節の格子上の項（\\( \delta V\_H \\) を含む）を ESM の \\( \delta V\_H \\) で評価するだけで、ESM 固有の項はありません。
  `on1`–`on3` では Green 関数が対称なので、エネルギーと力は整合します。
- 応力は ESM に対応していません（計算はされますが ESM の寄与を含みません）。
- 別に、`MD.Artificial_Force on` のとき `MD.Artificial_Grad`（Hartree/bohr、既定 0）を原子 1 のエネルギー勾配の法線方向成分に加えます
  （ESM が on のときだけ有効。試験用）。

### 2.6 MD 用の壁（`ESM.wall.*`）〔公開〕〔規約〕

〔公開〕マニュアル 49.1 節：固液界面の MD で原子が上端の媒質に近づかないよう、壁のポテンシャルを置きます。
`ESM.wall.position` はセルの上端から壁の原点までの距離（Å）、`ESM.wall.height` は壁の原点から 1.0 Å 内側に入った点でのポテンシャル（eV、既定 100.0）です。

〔規約〕

- `ESM.wall.switch on`（既定 off）のときだけ有効です。原子 \\( I \\) の法線方向の座標を \\( x\_I \\)、上端の面を \\( x\_b \\)（2.2 節）、
  \\( x\_w = x\_b - \texttt{ESM.wall.position} \\) として、\\( d = x\_I - x\_w > 0 \\) の原子に

$$
E\_{\mathrm{wall}}(d) = H\left(\frac{d}{1.89\\,\mathrm{bohr}}\right)^3,\qquad F\_I = -\frac{dE\_{\mathrm{wall}}}{dd} = -\frac{3Hd^2}{(1.89)^3}
$$

  の力を法線方向に加えます（\\( H \\) は `ESM.wall.height` を Hartree にしたもの。1.89 bohr を 1 Å の近似として使っています）。
- **\\( E\_{\mathrm{wall}} \\) は `Utot` に入りません**（力だけが加わる）。
- `ESM.wall.position` の既定値は 1.0 Å です（マニュアルの入力例の注記は 10.0）。負の値は入力エラーです。

### 2.7 `ESM.buffer.range`〔公開〕〔規約〕

〔公開〕マニュアル 49.1 節：媒質と波動関数が重ならないよう、原子と媒質の間に空ける幅（Å、既定 10.0）です。

〔規約〕この版では、`ESM.buffer.range` は `ESM.wall.switch on` のときだけ読み込まれ、**計算には使われません**
（原子が緩衝領域に入っていないかの検査は無効になっています）。

〔設計〕再実装は、原子のカットオフ球（PAO のカットオフ半径）が媒質の面から `ESM.buffer.range` 以内に入らないことを検査し、
違反は警告とします。

## 3. 一様電場（`scf.Electric.Field`）

### 3.1 概要〔公開〕

マニュアル 30 節：一様電場を鋸歯状のポテンシャルで表し、SCF と構造最適化に使えます。`scf.Electric.Field` に 3 成分を
GV/m（\\( 10^9 \\) V/m）で与えます（既定 0 0 0）。周期系では鋸歯の不連続面が物質中にあると数値的に不安定になりうる一方、
分子では不連続面が真空にあるので通常は問題ありません。

### 3.2 ポテンシャル〔規約〕

- 単位換算は \\( 1\ \mathrm{GV/m} = 0.1944688\times10^{-2} \\) Hartree/(\\( e \\) bohr) です（CODATA の値 \\( 1.944690\times10^{-3} \\) との差は相対 \\( 10^{-6} \\)）。
- 入力の 3 成分 \\( (E\_1, E\_2, E\_3) \\) は、それぞれ格子ベクトル \\( \mathbf a\_1, \mathbf a\_2, \mathbf a\_3 \\) の方向の成分として扱います
  （標準出力に表示される電場の向きは \\( \sum\_i E\_i\mathbf a\_i/\lVert\mathbf a\_i\rVert \\) の単位ベクトル）。
- 格子点 \\( \mathbf n = (n\_1,n\_2,n\_3) \\)（\\( 0 \le n\_i < N\_i \\)）の値は

$$
V\_{\mathrm{ef}}(\mathbf n) = \sum\_{i=1}^{3} E\_i\left(n\_i\lVert\mathbf h\_i\rVert + O\_i - c\_i\right)
$$

  です。\\( \mathbf h\_i \\) は格子の刻み（[グリッド](grid-poisson-xc.md) 1.1 節）、\\( O\_i \\) は格子の原点の第 \\( i \\) Cartesian 成分、
  \\( c\_i \\) は原子位置の算術平均の第 \\( i \\) Cartesian 成分です。
  格子ベクトルが Cartesian 軸に平行な直方体のセルでは、これは \\( V\_{\mathrm{ef}}(\mathbf r) = \mathbf E\cdot(\mathbf r - \mathbf c) \\) です。
  一般のセルでは、\\( \mathbf a\_i \\) 方向の距離 \\( n\_i\lVert\mathbf h\_i\rVert \\) と Cartesian の原点成分を混ぜた式になり、一様電場にはなりません。
- \\( V\_{\mathrm{ef}} \\) は電子のポテンシャルエネルギーで、格子上の局所ポテンシャルに加えます
  （非共線では対角の 11・22 成分）。電子は \\( \mathbf E \\) と逆向きに押されるので、\\( \mathbf E \\) は通常の物理的な電場の向き（正電荷が押される向き）です。
  〔公開〕マニュアルの「電子にかかる電場について定義」という説明は、この意味に読みます。
- 鋸歯の不連続面は、各方向の \\( n\_i = N\_i - 1 \\) と次の周期像の \\( n\_i = 0 \\) の間、すなわち格子の原点を通るセルの面です。跳びの大きさは \\( E\_i a\_i \\) で、平滑化はしません。
- \\( V\_{\mathrm{ef}} \\) は各 SCF の最初（各 MD・構造最適化ステップの始め）に、その時点の原子の重心で作り、SCF 中は固定です。格子の原点は計算の最初に固定されたままです。
- ESM と同時に使うことは禁止されていません（〔未確定〕：組み合わせの意味は未検証）。

### 3.3 エネルギー〔規約〕

出力ラベル `Uef` は

$$
U\_{\mathrm{ef}} = \Delta V\sum\_{\mathbf n} n(\mathbf r\_{\mathbf n})\\, V\_{\mathrm{ef}}(\mathbf n)
$$

で、`Utot` に入ります（[全エネルギーと力](energy-force.md) の表）。電子密度だけの項で、**原子核（価電荷 \\( Z\_I \\)）と電場の相互作用
\\( -\sum\_I Z\_I V\_{\mathrm{ef}}(\mathbf R\_I) \\) は含みません**。重心 \\( \mathbf c \\) を差し引いているので、\\( U\_{\mathrm{ef}} \\) には \\( -N\_{\mathrm e}\\,\mathbf E\cdot\mathbf c \\) 型の定数が入ります。

### 3.4 力〔規約〕

力は、\\( V\_{\mathrm{ef}} \\) を含む格子上の局所ポテンシャルで [グリッド](grid-poisson-xc.md) 6 節の基底関数の微分の項を評価したものだけです。
原子核にかかる力 \\( Z\_I\mathbf E \\) は加えず、重心 \\( \mathbf c \\) の原子位置への依存も微分しません。
その結果、

- 電場中の中性分子でも、力の総和は 0 にならず、およそ \\( -N\_{\mathrm e}\mathbf E \\)（電子が受ける力）になります。
- 一方、\\( U\_{\mathrm{ef}} \\) は重心とともに \\( V\_{\mathrm{ef}} \\) が動くので剛体並進で変わらず、`Utot` の原子位置での有限差分と力は一致しません。

〔設計〕再実装は fixture との照合のため既存の定義を「互換モード」として持ちますが、既定では原子核の項
\\( -\sum\_I Z\_I V\_{\mathrm{ef}}(\mathbf R\_I) \\) をエネルギーに加え、力に \\( Z\_I\mathbf E \\) を加え、重心による定数シフトは固定の基準点に置き換えます。
こうすると中性系では全エネルギーが並進不変になり、力とエネルギーが整合します（不連続面の近くに原子がない場合）。

## 4. 仮想原子（分数の核電荷）

### 4.1 作り方〔公開〕

マニュアル 32 節：分数の核電荷を持つ擬ポテンシャルを ADPACK で作ります。ADPACK の入力で `AtomSpecies`（核電荷）、
`total.electron`、`valence.electron` と占有数を分数で与えます（例：C と N の間の核電荷 6.2、価電子 4.2）。
基底関数も同じ分数核電荷の仮想原子について作る必要があります。中性原子ポテンシャルを PAO ファイルの原子密度から作るためです。
例として、ダイヤモンドの 8 個の C のうち 1 個を核電荷 6.2 の仮想原子にした入力 `DIA8-VA.dat` があります。

### 4.2 OpenMX での扱い〔規約〕

仮想原子のための特別な処理はなく、PAO・VPS ファイルの値がそのまま使われます。分数の値が通る箇所は次のとおりです。

- PAO ファイルと VPS ファイルの `AtomSpecies` は一致しなければなりません（実数として比較。不一致は入力エラー）。
  例外は VPS の `AtomSpecies` が 0（空原子）の場合です。
- 種の価電荷は \\( Z\_I = \texttt{valence.electron} + \texttt{AtomSpecies} - \texttt{total.electron} \\)（VPS ファイルの値）で、分数になりえます。
  この \\( Z\_I \\) が電子数（1.1 節）、`Ucore` の点電荷、原子密度の規格化（[グリッド](grid-poisson-xc.md) 2.2 節：
  \\( 4\pi\int r^2 n^{a}\_I dr = Z\_I \\) に定数倍）に使われます。
- 整数の原子番号が必要な箇所（ラベルなど）では、\\( 0 < \texttt{AtomSpecies} < 1 \\) なら 1、それ以外は小数部を切り捨てた値を使います。

### 4.3 種ごとの電子数の上書き〔規約〕

マニュアル 32 節にはありませんが、`<Number.of.Electrons.Species` ブロック（各行に種の名前と実数）を与えると、
新しいファイルを作らずに種の価電荷を変えられます。

- その種の \\( Z\_I \\) を与えた値 \\( Z'\_I \\) に置き換えます。
- VPS の局所ポテンシャル \\( V^{\mathrm{loc}}\_I \\) を \\( Z'\_I/Z\_I \\) 倍します。
- 原子密度は \\( Z'\_I \\) に規格化し直し、そこから原子 Hartree ポテンシャルと \\( V^{\mathrm{na}}\_I \\) を作り直します
  （[中性原子](neutral-atom.md) の通常の手順）。
- 非局所項、部分内殻密度、PAO 基底は変えません。

〔未確定〕この機能の公開資料での位置づけ（マニュアルの他の節での記載）は未確認です。

## 5. 内殻準位の絶対束縛エネルギー（XPS）

### 5.1 束縛エネルギーの定義〔公開〕

技術ノート 24（Eq. 1–4）とマニュアル 60.1 節：初期状態（\\( N \\) 電子の基底状態）の全エネルギー \\( E\_i^{(0)}(N) \\) と、
内殻に正孔を 1 つ作った終状態の全エネルギー \\( E\_f^{(0)}(N-1) \\)（\\( N-1 \\) 電子）から

$$
E\_b^{\mathrm{(gas)}} = E\_f^{(0)}(N-1) - E\_i^{(0)}(N),\qquad
E\_b^{\mathrm{(bulk)}} = E\_f^{(0)}(N-1) - E\_i^{(0)}(N) + \mu\_0,\qquad
E\_b^{\mathrm{(metal)}} = E\_f^{(0)}(N) - E\_i^{(0)}(N)
$$

とします。\\( \mu\_0 \\) は初期状態の計算の化学ポテンシャル（出力の `Chemical Potential (Hartree)`）です。

- 固体の式は、分光器の真空準位を試料の化学ポテンシャル＋分光器の仕事関数とおき（電気的接触で化学ポテンシャルがそろう）、
  化学ポテンシャルの任意の基準のずれ \\( \Delta\mu \\) が \\( E\_i \\) と \\( E\_f \\) で \\( N\Delta\mu - (N-1)\Delta\mu \\) として打ち消すことから導かれます。
  したがって真空準位も仕事関数も必要なく、基準は初期状態の \\( \mu\_0 \\) です。
- 金属の式は Janak の定理 \\( E\_f(N-1) - E\_f(N) = -\mu\_0 \\) によるもので、中性化した終状態（正孔の電荷を伝導電子が遮蔽）を使い、
  セルの大きさに対する収束がずっと速くなります。ギャップのある系には使えません（技術ノート 24：NH₃ で 1.2 eV ずれる）。
- \\( E\_f \\) は DFT のエネルギーにペナルティ項（5.2 節）を加えたもの（出力の `Utot`、`Uch` を含む）です。

### 5.2 ペナルティ汎関数〔公開〕〔規約〕

〔公開〕技術ノート 24（Eq. 5–10）：

$$
E\_f = E\_{\mathrm{DFT}} + E\_{\mathrm{pen}},\qquad
E\_{\mathrm{pen}} = \frac{1}{V\_B}\int\_B d^3k\sum\_\mu f\_\mu(\mathbf k)\\,\langle\psi\_\mu(\mathbf k)\rvert\hat P\lvert\psi\_\mu(\mathbf k)\rangle,\qquad
\hat P = \lvert R\\,\Phi\_{JM}\rangle\\,\Delta\\,\langle R\\,\Phi\_{JM}\rvert
$$

\\( \Phi\_{JM} \\) は球対称ポテンシャル中の Dirac 方程式の角度部分（2 成分スピノル）で、\\( J = l+\tfrac12 \\)、\\( M = m+\tfrac12 \\) では

$$
\Phi\_{JM} = \sqrt{\frac{l+m+1}{2l+1}}\\,Y\_{lm}\\,\alpha + \sqrt{\frac{l-m}{2l+1}}\\,Y\_{l,m+1}\\,\beta,
$$

\\( J = l-\tfrac12 \\)、\\( M = m-\tfrac12 \\) では

$$
\Phi\_{JM} = \sqrt{\frac{l-m+1}{2l+1}}\\,Y\_{l,m-1}\\,\alpha - \sqrt{\frac{l+m}{2l+1}}\\,Y\_{lm}\\,\beta
$$

です（\\( \alpha, \beta \\) は上・下スピン）。大きな \\( \Delta \\) で目的の状態の占有を罰すると、SCF の中で正孔ができ、
内殻・価電子の遮蔽、スピン軌道相互作用、交換が自己無撞着に取り込まれます。Kohn–Sham 方程式には \\( \hat P \\) が加わります。
技術ノート 24 は \\( \Delta = 100 \\) Ry を使ったと述べています。

〔規約〕既存実装での具体形は次のとおりです。

**射影の関数**：正孔を作る原子 \\( C \\)（`<core.hole.state` の 1 番目の値、原子の通し番号）の、指定した \\( l \\)（2 番目の値 `s`・`p`・`d`・`f`）の
**最初の動径関数（\\( \zeta = 0 \\)）の基底関数** \\( \chi\_{\mu} = R\_{l0}(r)S\_{l\mu} \\)（\\( \mu = 0,\dots,2l \\)、[PAO 基底](pao-basis.md) の並び）を使います。
内殻を価電子として含む擬ポテンシャルと、それに合わせた基底（例：`C_PBE19_1s` と `C7.0_1s-…`、終状態は正孔用に最適化した `C7.0_1s_CH-…`）を使うので、
\\( l \\) チャネルの最初の動径関数が目的の内殻軌道になります。

**ペナルティの大きさ**：

$$
\Delta = \texttt{scf.base.penalty.value} - \varepsilon\_{\mathrm{core}}
$$

`scf.base.penalty.value` は Hartree（既定 20.0）、\\( \varepsilon\_{\mathrm{core}} \\) は原子 \\( C \\) の種の PAO ファイルの
`Lmax=` で始まる固有値の表（各行 `l mu` \\( l \\) \\( \mu \\) 固有値、Hartree）の \\( (l, \mu=0) \\) の値です
（例：`C6.0_1s.pao` の 1s は \\( -10.022 \\) Ha なので \\( \Delta \approx 30.0 \\) Ha）。表に値がなければ \\( \varepsilon\_{\mathrm{core}} = 0 \\) です。
技術ノートの「100 Ry」とは決め方が異なります。

**状態の指定（3 番目の値 \\( j \\)）**：\\( 0 \le j \le 2(2l+1) \\)。

| 場合 | \\( j = 1, \dots, 2l+1 \\) | \\( j = 2l+2, \dots, 2(2l+1) \\) | \\( j = 0 \\) |
|---|---|---|---|
| 共線（`scf.SpinPolarization on`）、または非共線で擬ポテンシャルが \\( l \\) 依存 | 上スピンの実軌道 \\( \mu = j-1 \\) | 下スピンの実軌道 \\( \mu = j-2l-2 \\) | \\( l \\) 殻の全軌道・両スピン |
| 非共線で \\( j \\) 依存の擬ポテンシャル（`scf.SpinOrbit.Coupling on`） | \\( J = l+\tfrac12 \\)、\\( M = J, J-1, \dots, -J \\) の順（\\( 2l+2 \\) 個） | 続けて \\( J = l-\tfrac12 \\)、\\( M = J, \dots, -J \\) | 全 \\( (J,M) \\)（殻全体） |

表の 1 列目と 2 列目の境界は、\\( j \\) 依存の場合だけ \\( 2l+2 \\) と \\( 2l+3 \\) の間に移ります（\\( J = l+\tfrac12 \\) が \\( 2l+2 \\) 個のため）。
`s` では \\( J = \tfrac12 \\) だけで、\\( j = 1, 2 \\) が \\( M = \pm\tfrac12 \\) です。

> **マニュアル 60.2 節についての注記**：本文は軌道の番号を「1 から \\( 4l+1 \\)」としていますが、同節の表と既存実装はどちらも
> 1 から \\( 2(2l+1) \\) です（\\( j = 0 \\) も受け付けます）。

**行列の形**：スピン成分を含めた単位ベクトル \\( \mathbf c \\)（実軌道 \\( \mu \\) とスピンの \\( 2(2l+1) \\) 次元）で目的の状態を表し、
\\( D = \Delta\\,\mathbf c\mathbf c^\dagger \\) とします。共線の指定では \\( \mathbf c \\) は単位ベクトル \\( e\_{(\mu,\sigma)} \\)、
\\( j \\) 依存の指定では上の \\( \Phi\_{JM} \\) を実球面調和関数に変換したもの
（\\( Y\_{lm} = \sum\_\mu \overline{U^{(l)}\_{\mu m}}\\,S\_{l\mu} \\)、[PAO 基底](pao-basis.md) の \\( U^{(l)} \\)）、\\( j = 0 \\) では \\( D = \Delta\\,I \\) です。
基底関数の行列要素は

$$
H^{\mathrm{CH},\sigma\sigma'}\_{I\alpha,J\beta}(\mathbf L) = f(d\_{IJ})\sum\_{\mathbf L'}\sum\_{\mu\nu}
S\_{I\alpha,\\,(C+\mathbf L')\mu}\\; D^{\sigma\sigma'}\_{\mu\nu}\\; S\_{(C+\mathbf L')\nu,\\,J\beta+\mathbf L}
$$

です。\\( S \\) は重なり積分（[二中心積分](two-center-overlap-kinetic.md)、\\( I = C \\) の on-site ブロックを含む）、
\\( f \\) は非局所擬ポテンシャルと同じ減衰関数（[非局所擬ポテンシャル](nonlocal-pseudopotential.md) 3.4 節、\\( r\_{\mathrm{cut}} = r\_{c,I}+r\_{c,J} \\)）、
原子対の範囲も同じです。\\( \mathbf L' \\) の和は原子 \\( C \\) の**すべての周期像**にわたります（正孔はスーパーセルのすべての周期像に 1 つずつあります）。
この行列を Hamiltonian に加え（共線では上下スピンのブロックに、非共線では 2×2 の全成分に）、スピン軌道相互作用のあるときは虚部も加えます。

**エネルギーと力**：`Uch` \\( = \sum\_{\sigma\sigma'}\sum\_{\mathrm{pairs}}\rho^{\sigma'\sigma}H^{\mathrm{CH},\sigma\sigma'} \\)（[全エネルギーと力](energy-force.md) の `Unl` と同じトレースの規則）で、
`Utot` に入ります。力は \\( S \\) の微分と減衰関数の微分から、非局所項と同じ形で加えます。

**前提**：`scf.core.hole on` はスピン分極（`on` か `nc`）が必要で、`off` は入力エラーです。
`s` 以外の殻ではマニュアル 60.2 節が `nc`（スピン軌道相互作用あり）を求めています。

### 5.3 周期像と Hartree ポテンシャルの分割〔公開〕〔規約〕

〔公開〕技術ノート 24 とマニュアル 60.3 節：ギャップのある系の終状態は荷電状態のまま扱い（光電子の脱出時間が短いため中性化しない）、
周期像の正孔どうしの静電相互作用を除くため、終状態の密度を \\( n\_f = n\_i + \Delta n \\)（\\( n\_i \\) は初期状態の周期的な密度、
\\( \int\Delta n = -1 \\)）と分け、

$$
V\_H = V\_H^{(\mathrm P)}[n\_i] + V\_H^{(\mathrm{NP})}[\Delta n],\qquad
\tilde V\_H^{(\mathrm{NP})}(\mathbf G) = \frac{4\pi}{G^2}\left(1 - \cos(GR\_c)\right)\Delta\tilde n(\mathbf G)
$$

とします。\\( V\_H^{(\mathrm P)} \\) は通常の周期境界の解、\\( V\_H^{(\mathrm{NP})} \\) は球形 Coulomb カットオフ（\\( R\_c \\) は最短の格子ベクトルの長さの半分）の解です。
\\( \Delta n \\) が半径 \\( R \\) の球に収まるとき、\\( R\_c \ge 2R \\) かつ \\( 4R < L \\) なら正孔は周期像から静電的に孤立します。

〔規約〕

- この分割は、`scf.coulomb.cutoff on`、`scf.restart on`、**`scf.restart.filename` を明示** の 3 つがそろったときに有効になります
  （`scf.core.hole` の値によらない）。このとき再開ファイルの密度（初期状態の SCF の密度）を \\( n\_i \\) として保持し、SCF の最初に
  \\( \delta n\_i = n\_i - n^{a} \\) から \\( V\_H^{(\mathrm P)} \\) を周期境界で一度だけ解きます（`scf.core.hole on` のとき）。
  以後の各 SCF では \\( n - n\_i \\) にカットオフ付きの解を適用して \\( \delta V\_H = V\_H^{(\mathrm P)} + V\_H^{(\mathrm{NP})}[n - n\_i] \\) とします。
  再開ファイルの密度は SCF の初期密度にもなります。
- `UH1` は \\( \tfrac12\Delta V\sum\_{\mathbf n}\delta n\\,\delta V\_H \\)（\\( \delta n = n - n^{a} \\)、\\( \delta V\_H \\) は上の和）です。
  2 つの核が違うので、これは静電エネルギーの対称な分割（\\( \tfrac12 n\_i V^{(\mathrm P)}[n\_i] + \Delta n\\,V^{(\mathrm P)}[n\_i] + \tfrac12\Delta n\\,V^{(\mathrm{NP})}[\Delta n] \\)）とは交差項が一致しません。既存実装の定義として記録します。
- 気体分子（マニュアル 60.2 節）では再開ファイルを使わず、初期・終状態とも `scf.coulomb.cutoff on` で \\( \delta n \\) 全体にカットオフを適用します（[グリッド](grid-poisson-xc.md) 3.3 節）。
- 分割の 3 条件がそろっているのに `scf.core.hole off` の場合、\\( V\_H^{(\mathrm P)} \\) は計算されず 0 のままです（周期部分の Hartree ポテンシャルが欠ける）。再開ファイルの読み込みに失敗した場合も同様です。
- **ESM との併用**（マニュアル 60.4 節）：`ESM.switch` が on で `scf.core.hole on` かつ再開ファイルを読めた場合、
  \\( V\_H^{(\mathrm P)} \\) を ESM（2 節）で解き、その後その計算の残りでは ESM を無効にします（壁の力も含む）。
  したがって終状態は `scf.coulomb.cutoff on` と組み合わせる必要があります（off だと、以後 \\( \delta n \\) 全体を周期境界で解いてしまう）。
  ESM は初期状態の中性の密度にだけ使うので `on1` を使います。

### 5.4 ΔSCF の手順〔公開〕〔規約〕

k 点、電子温度、スピンの扱いをそろえます。終状態では正孔の原子だけ種を正孔用の基底（`…_CH`）に替えます。

## 6. 実装への要求〔設計〕

- **Poisson ソルバーの差し替え**：Poisson 方程式は「\\( \delta n \\)（格子上）→ \\( \delta V\_H \\)（格子上）」の関数として抽象化し、
  周期境界、球形カットオフ、ESM（`on1`–`on4`）、差分モード（5.3 節）を同じ型の実装として選べるようにします。
  ESM の実装は 1 次元の Green 関数（2.3 節）を引数に取る形にし、端の平滑化（2.4 節の 4）は既存実装との照合用の選択肢として分離します。
- **外部ポテンシャルの登録**：一様電場、ESM の `on4` の電位差、壁などの外部項は、「格子ポテンシャルへの寄与」「エネルギーへの寄与」「原子への力」の 3 つを返す
  モジュールとして登録し、互換モードと物理的に整合するモード（3.4 節、2.5 節の `on4`、2.6 節の壁のエネルギー）を切り替えられるようにします。
- **ペナルティ項**：内殻正孔の \\( H^{\mathrm{CH}} \\) は、非局所擬ポテンシャルと同じ「射影子＝ある原子上の関数」の三中心の構造なので、
  同じ原子対の範囲・減衰関数・力の計算の枠組みで実装し、射影子として「指定原子の基底関数」を与えるだけにします。
  \\( \mathbf c \\)（目的の状態）は、共線の指定と \\( (J,M) \\) の指定を同じ \\( 2(2l+1) \\) 次元のベクトルとして扱います。
- **仮想原子**：種のデータ（\\( Z\_I \\)、\\( V^{\mathrm{loc}} \\)、\\( n^{a} \\)）は実数で持ち、整数の原子番号に依存する処理を作らないこと。
- **再開ファイル**：差分モードで使う初期状態の密度は、格子（分割数・原点）が一致することを検査します。
