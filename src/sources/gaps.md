# 公開資料の空白

公開資料（技術ノート・論文・マニュアル）だけでは再実装に足りない項目の一覧です。
各項目は、記述者が〔規約〕として補うか、このノートで〔設計〕として決め直します。

## 全体に関わる規約

| 項目 | 状況 | 対応 |
|---|---|---|
| 実球面調和関数の並び順・符号 | マニュアルは「実球面調和関数」とのみ記載 | [PAO 基底](../modules/pao-basis.md) に〔規約〕として記載済み |
| PAO・VPS ファイルの形式 | マニュアルに概要のみ | PAO は記載済み、VPS は一部 |
| 二中心積分の波数格子・積分点数 | 技術ノート 15 に例示のみ | 〔未確定〕 |
| 軌道・原子・周期像・スピンの添字規約 | 記載なし | [疎ブロック形式](../design/sparse-block-format.md) で〔設計〕 |
| 実空間グリッドの決め方（カットオフから格子数） | 技術ノート 1 に概要 | 〔未確定〕 |
| k 点の生成（TRIM 点を含む） | マニュアル 15 節のみ | 〔未確定〕 |

## 数値手法

| 項目 | 状況 |
|---|---|
| S の正則化（固有値の置換・次元削減）の閾値と方式 | 記載なし。経路ごとに異なる（[一般化固有値](../modules/generalized-eigen.md)） |
| auto-Kerker、SCF の自動調整（マニュアル 16.2、16.3） | 技術ノートなし |
| 構造最適化の EF・RF・DIIS（マニュアル 18） | 技術ノート 7 は一般論のみ |
| MD の熱浴・圧力浴（NVT_NH、NPT など） | マニュアルのみ |
| EXX を SCF にどう組み込むか | 積分の技術ノートのみ |
| DFT-D2・D3 | 記載なし |

| 項目 | 状況 |
