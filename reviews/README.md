chapters, before the repository was reorganized and translated into English (2026-11-10). They are kept in
Japanese as historical records. File paths in them refer to the old layout (`src/modules/...`, now
`src/methods/lcao-openmx/modules/...`). The translation did not intend to change content; a re-review of the
English text should be recorded here as a new file.
